# 知序洛谷提交桥接

Chrome/Edge Manifest V3 插件。插件使用用户当前浏览器中的洛谷登录状态，洛谷账号密码和 Cookie 不会传给知序服务器。

## 安装

1. 在洛谷模式的比赛题目工作区打开配置教程，下载 ZIP 并解压到一个固定目录；安装后不要移动或删除该目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中解压后的 `browser-extension` 文件夹。
4. 插件 ZIP 已由管理员配置知序网站来源；安装时按浏览器提示允许访问该站点，无需填写地址。
5. 刷新知序页面，在同一浏览器登录 `https://www.luogu.com.cn` 并保持洛谷页面打开。
6. 回到比赛题目工作区，点击“检测洛谷登录状态”；显示已连接后开始答题。洛谷拒绝提交并提示验证码时，插件会打开对应的洛谷题目页；确认账号已登录，按洛谷页面提示完成验证，再回到本站重试。若页面没有显示验证提示，请在该题的洛谷提交区域查看页面提示。

管理员修改网站来源后，用户需要下载新版插件 ZIP，在扩展程序管理页重新加载已解压插件。

知序检测到插件版本较旧时会自动打开本教程；下载新版 ZIP 后，在浏览器扩展程序管理页点击插件的刷新按钮，再刷新知序页面。

每次提交由用户在本站点击后发起，代码经浏览器发送给洛谷。插件只在洛谷前端已提供的页面信息中读取账号登录状态和提交结果；它不导出、不保存、不上传 Cookie。插件使用洛谷网站当前的页面提交接口，平台改版可能导致提交暂时不可用。

目前编辑器只提供 Python 3。题目、比赛时间及本站记录由知序管理；提交及隐藏测试评测由洛谷完成。题目管理员需填写合法的洛谷题号，并录入本站展示用的题面和样例。
