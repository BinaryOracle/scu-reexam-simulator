# 必知必会数学技巧

## 学习目标

理解模运算的适用公式、二分快速幂及最大公约数，防止中间值溢出。

## 模运算不能只处理最终答案

加法与乘法可先分别取模，再组合后取模。减法若可能为负，可在取模后补模数；C++ 负数余数不一定落在期望的 [0,m) 范围。除法不能直接沿用这些规则，模意义下的除法需要满足条件的逆元。

快速幂把指数按二进制展开，每轮平方底数，并在指数最低位为 1 时乘入答案：

```cpp
long long modPow(long long base, long long exp, long long mod) {
    // 前提：exp >= 0，1 <= mod <= 1e9+7，base 在 long long 范围内
    base = (base % mod + mod) % mod;
    long long answer = 1 % mod;
    while (exp > 0) {
        if (exp & 1) answer = answer * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return answer;
}
```

限制模数范围是为了保证两项相乘仍能放进 long long；模数接近类型上界时需其他防溢出乘法，不能认为“乘完再取模”自动安全。

欧几里得算法使用 gcd(a,b)=gcd(b,a%b)，直到 b=0。最小公倍数可以先计算 a/gcd(a,b) 再乘 b，降低中间值规模，但最终结果仍可能溢出。对 0 和负数应按题目定义规范化；0 与 0 的组合尤其不要直接除以 gcd。
