# 默认算法入门课程设计

## 目标与范围

在课程广场默认提供一门“算法入门：刷题框架与经典算法”公开课程，面向希望按顺序掌握算法基础的学员。来源是 labuladong 的算法笔记“算法刷题速成”教程：https://labuladong.online/zh/algo/home/ 。保留来源章节顺序，将免费公开内容整理为可阅读的 Markdown 学习笔记，并为每课提供原文链接、学习目标及练习建议；不将仅有链接的目录冒充完整课程正文，不复制原站交互、视频或会员内容。

## 来源核对

2026-11-21 未登录公开页面目录共 133 条，初检 42 条未发现会员内容组件，91 条包含会员内容组件，后者整篇跳过。实际目录与页面内文章索引数组数量不一致，以侧边栏目录为准。完整清单见 ../../research/labuladong-algorithm-course-inventory.json 。分类只是页面可访问性证据，正式正文整理前还需核读免费候选内容。

章节保留课程导览、准备工作、第零章核心刷题框架、第一章经典数据结构、第三章动态规划、第四章数学技巧。第二章条目均含会员内容，不建立空章节。原站后续可能调整免费范围，课程说明标注整理日期。

## 学习与管理体验

沿用现有“课程—章节—课时”结构，直接在已有课程详情和学习页阅读正文、切换课时和标记完成。无需新增导览层级、外部账号或新的课程类型。课程介绍明确原作者及来源，封面沿用系统预设，课程可以由管理员编辑、归档或删除。

每课正文包括内容来源、简明学习目标、独立组织的核心知识、必要的代码或推导、易错点及自测任务。站点说明和工具安装类课时保留其导学性质，不强制用户安装第三方插件。

## 默认导入

在已有数据库初始化事务中执行一次性课程导入，使用稳定的种子标识防止重复创建；保存管理员对课程、章节和正文的后续编辑，删除后不在下一次启动时复活。新数据库和已有数据库都可获得默认课程。无需访问外网或调用大模型才能启动。

正文作为现有 Markdown 课程资源保存，继承课程资源权限、下载、预览与完成进度。采用现有媒体目录配置，避免写死部署路径。导入失败时回滚数据库事务并报告原因，资源文件不能与已有用户上传文件重名。

## 验证

使用临时数据库和媒体目录验证新安装、已有课程、重复初始化、编辑保留、删除保留；通过现有课程 API 验证普通用户可在课程广场找到课程、加入并阅读全部课时、查看安全渲染 Markdown 和记录进度。核对目录顺序、免费课时覆盖率、来源链接和正文完整性，确保未将会员页面引入课程。执行课程相关测试与 git diff 检查，不启动常驻服务。
