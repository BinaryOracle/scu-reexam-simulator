# 直播课堂 V1

面向 50 人以内互动小班，在知序复用账号与暖米白、朱红视觉体系。管理员管理课程、课次、名单；课程主持人属于课程内授权，不新增全局教师角色。课程资料、评论、录播访问均需要课程成员权限。

课堂采用 LiveKit SFU：共享内容为主舞台，底部参与者缩略图，右侧可折叠评论/成员/资料面板，固定底部设备与互动操作栏。入会前检测设备，默认关闭麦克风和摄像头。学员举手申请发言/共享，主持人授权后学员主动开启，服务端同步更新媒体发布权限；撤销权限必须同步撤销发布。仅允许一个共享者。

课程包含多个课次；未开始、直播中、已结束使用独立状态。主持人开启/结束课次，离开不结束课堂。服务端 Egress 录制共享画面与课堂音视频，签名事件更新录制状态，录播文件通过鉴权流式访问；未配置 LiveKit/Egress 时提供可操作提示，不伪造连通或录制成功。课堂互动保存在 SQLite，短轮询恢复评论与状态，音视频由 LiveKit 传输，实例外置部署。资料存储私有路径，限制类型与大小，上传失败不发布元数据。

配置集中在 [live]；凭据仅服务端读取。浏览器 SDK 固定版本本地托管。部署文档包含 LiveKit、TURN、Egress、文件存储、TLS 与容量验证步骤。测试涵盖成员隔离、课次状态、评论与举手授权、媒体 token、文件访问、录播事件、离开清理和响应式页面。
