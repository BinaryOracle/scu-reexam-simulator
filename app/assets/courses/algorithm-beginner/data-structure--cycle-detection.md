# 环检测算法

## 学习目标

区分有向图中的访问完成与当前递归路径，理解 DFS 和入度消除两种判环。

## 访问过并不等于存在环

有向图中多个路径可能到达同一节点，不能因为见过它就判断有环。DFS 需要区分未访问、当前路径中、已完成三种状态；只有遇到当前路径中的节点才构成回边。

```text
dfs(u):
    若 state[u] 为当前路径，返回存在环
    若 state[u] 为已完成，返回无新增环
    标记 u 为当前路径
    对每条 u -> v，若 dfs(v) 发现环则立即返回
    标记 u 为已完成
    返回无环
```

从每个未访问节点启动 DFS，才能覆盖不连通的有向图。对无向图不能直接照搬这条判定，因为走回父节点是无向边的正常现象，需要处理父边或边编号。

## 用入度消除观察剩余节点

另一种做法统计入度，将所有入度为 0 的节点入队，逐个删除其出边。若最后处理节点数少于总数，剩下部分被有向环阻塞。注意剩余节点不一定全在环上，也可能只是依赖环的下游节点。

课程依赖可把“先修 a 才能修 b”建成 a→b。建边方向要与入度含义一致，不能把先修数量统计反过来。邻接表两种算法都为 O(V+E)，额外空间 O(V)；DFS 还要考虑最坏 O(V) 的栈深。

## 动手练习

1. 对 0→1、0→2、1→2 说明为何不是环。
2. 加入 2→0 后跟踪 DFS 三色变化。
3. 用入度消除实现判环，并测试自环、无边图和不连通图。
