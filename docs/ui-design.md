# V1.0 界面设计

参考提供的校园插画配色，以校门朱红为主色，暖米白作为页面背景，浅金和草木绿作为辅助色。图片仅作颜色参考，页面没有引用图片中的文字或第三方标识。

| 用途 | 颜色 |
| --- | --- |
| 主按钮、品牌与当前导航 | `#a34234` |
| 登录页背景 | `#6f2926` |
| 工作台背景 | `#f8f5ef` |
| 正文 | `#443630` |
| 边框 | `#eae2d8` |
| 通过状态背景／文字 | `#edf1e5` / `#6b8051` |

`app/static/style.css` 的根变量管理主色、背景、正文和边框。登录页采用两栏布局；工作台在桌面采用侧边导航，620px 以下切换为顶部导航。侧边导航可折叠，面试环节以默认隐藏的左缘浮层展开。上机列表、比赛详情和答题工作区独立显示；桌面题面和代码区可分栏、分别滚动，窄屏通过页签切换题面与代码。

前端通过 ES modules 分离页面入口、网络请求、共享组件、面试状态和上机状态。页面内容以 DOM 文本写入，题面、回答和模型输出不作为 HTML 执行。表单保留显式标签与焦点标识，长表格在其容器内滚动，减少动画偏好由媒体查询处理。

浏览器检查使用独立临时数据库验证了：考生登录、面试创建、环节切换、未保存文本保留、回答保存、比赛切换、代码草稿恢复、提交状态表格、管理员只读复核、创建比赛、测试 JSON 校验和题目保存。正式数据库未插入这些测试场次和比赛。375px 宽度的考生首页没有横向溢出。此次界面检查没有采集真实麦克风音频或调用真实 AI/ASR。

预览：[工作台](screenshots/workspace.jpg)、[登录页](screenshots/login.jpg)。后端回归测试为 `python -m pytest -q`；前端语法使用 Node 的模块语法检查验证，无前端构建步骤。

## 后台用户管理

后台沿用前台朱红、米白、浅金与草木绿主题，提供账号统计、用户名/邮箱搜索、启停筛选、邮箱信息、行内次数编辑以及用户名/密码重置和删除操作。创建账号保留普通用户与管理员身份选择，可填写登录邮箱；不再展示或维护两项模块权限开关。普通管理员只能看到普通用户，超级管理员管理全部账号。窄屏表格在自身容器内滚动，对话框限制高度并可滚动。

前台默认邮箱验证码登录，账号密码作为平级切换入口；后台保持管理员账号密码登录。发送状态就地显示，重发按钮显示冷却倒计时，隐藏表单不参与浏览器必填校验。验证码错误不会触发“会话已过期”提示或覆盖登录页状态。

## 面试准备、作答与复盘

准备页不显示环节或个人 PPT，提供上传、麦克风检测、音量条与试听。开始时自动录音，顶部中央紧凑计时器显示录音状态；后台转写按环节保存，作答时不显示实时字幕、全文校对、回答回顾和底部录音面板；结束后回顾内容集中到页面底部。自我介绍完成按钮不要求用户手动停止录音，切换环节主录音持续。

记录首页右上角显示「开始新面试」；详情页同一位置改为醒目的描边按钮「返回面试记录」，不再显示新面试按钮或重复的「当前练习」标题。正在录音时返回会确认结束并保存。结束面试按钮移到环节底部，在完成自我介绍／下一环节按钮之后，不再占据悬浮闹钟和标题行。返回首页清理重新渲染生成的详情按钮、计时器和沉浸状态，恢复主导航；切换环节回到页面顶部。

结束后默认返回 001 自我介绍，支持逐环节只读复盘、PPT 放映和全程录音回听。英文问答的下一环节直接进入专家问答。专家页在桌面将大幅 PPT 放在左侧，问题标题、QUESTION 05 和可滚动正文放在右侧；环节导航右端提供结束面试，下方居中提供生成整场点评。结束、超时和返回只保存面试，只有主动确认生成点评才调用 AI；模型失败可重试。麦克风拒绝授权时不开始计时，识别失败保留录音，上传失败显示重试与下载入口。刷新后明确提示恢复录音，倒计时不重置。

正式面试隐藏主导航及其展开按钮，保留独立环节抽屉；PPT 支持上下方向键。复盘页面按内容收紧高度，避免整屏空白；全程录音播放器不随环节切换重建。题库每页显示 10 题，筛选变化自动返回首页；搜索与筛选在手机端换行，账号表格提供横向滚动提示。个人主页购买入口通过 `credits.shop_url` 配置，链接以新标签页打开，不影响本站兑换流程。

共享提示位于底部安全区，提供关闭按钮；提示文字不拦截底层操作，避免错误信息挡住返回或展开导航。成功登录清除上一会话的提示。卡密列表筛选保留尚未提交的默认次数输入。上机代码视口高度固定并可拖动调整，长代码与行号在视口内同步滚动，编辑器标题同时显示所选比赛的剩余时间。

面试中的通知保持底部紧凑高度，不同时设置上下定位，以免提示背景被拉伸遮挡 PPT。界面预览：[专家问答](screenshots/expert-ui-v8.jpg)。

整场面试点评默认展开，点击标题区域可收起或展开，支持键盘操作；同一页面切换环节或重新打开同场记录时保留折叠状态，退出登录后清除。

专家问题采用独立卡片：固定的标题与环节编号、可聚焦滚动的正文；语音自动播放，不展示底部播放器或问题重播按钮。正文以常规字重和舒适行距展示，保留模型段落；长文在卡片内部滚动，桌面受面试视口高度约束，窄屏限制正文最大高度。正文区域获得焦点后，上下键滚动文本，不触发 PPT 翻页。

生成点评期间允许继续复盘、切换环节和返回首页，仅生成按钮禁用；提示区与记录卡片显示生成状态，异步结果只更新对应面试，不跳转或覆盖其他场次。专业课复盘并列展示换题前、换题后题目，窄屏纵向排列。正式环节提供自动语音提示和“环节播报”重播入口，专家环节依次播报环节提示、引导语、问题正文；回顾不自动播报。

整场点评使用渲染后的 Markdown 展示标题、强调、段落、列表、引用、分隔线、代码及表格；采用暖色正文卡片，表格和代码在窄屏内独立横向滚动，保留收起与展开功能。原文保存在数据库，展示方式变更不重新调用 AI。

后台面试归档先展示用户，每组默认收起；摘要显示用户名、最近面试时间和完成场数，按最近面试排序。用户名搜索即时过滤归档，返回详情后保留展开状态；用户改名通过稳定 ID 保持同一归档，管理员可见范围由服务端过滤。

个人主页提供账号与安全面板，邮箱只读展示，通过独立对话框验证新邮箱完成换绑；改名、改密码及注销沿用同一弹窗布局和表单错误样式。密码变更及注销使用当前邮箱的专用验证码，注销还需输入当前用户名确认。超级管理员界面显示无法自行注销的说明。
