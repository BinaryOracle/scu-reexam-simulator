# 滑动窗口算法核心代码模板

## 学习目标

维护连续区间状态，区分最长合法窗口与最短覆盖窗口的更新时机。

## 统一窗口含义

把当前窗口定义为左闭右开 `[left, right)`。右端加入元素时更新计数，左端移除元素时做相反更新。关键问题是：何时窗口非法、何时收缩、答案在哪个时刻更新。不同题目的三个答案并不相同。

以“最长无重复连续子串”为例：加入字符后，只要该字符计数超过 1 就缩小窗口，恢复合法后再记录长度。

```cpp
int longestUnique(const string& s) {
    vector<int> count(256, 0);
    int left = 0, best = 0;
    for (int right = 0; right < (int)s.size(); ++right) {
        ++count[(unsigned char)s[right]];
        while (count[(unsigned char)s[right]] > 1) {
            --count[(unsigned char)s[left++]];
        }
        best = max(best, right - left + 1);
    }
    return best;
}
```

这段代码按字节处理字符串，适用于题目限定的 ASCII 字符集；不把 UTF-8 多字节字符误当成单个字符。对最短覆盖问题，窗口满足覆盖时已经可行，应先记录长度，再收缩尝试更短答案。

虽然有内层循环，每个元素最多进入、离开窗口一次，所以维护计数为常数成本时整体为 O(n)。若题目条件不支持单调收缩，例如包含负数的任意区间和问题，不能直接照搬常用正数窗口。

## 动手练习

1. 手算字符串 abca 的窗口和字符计数。
2. 解释最短覆盖与最长无重复子串为何在不同位置更新答案。
3. 为全相同、空串、全不同三种输入测试示例函数。
