# 动态规划解题套路框架

## 学习目标

从状态含义推导转移与边界，识别重复子问题并正确选择遍历方向。

## 四步定义

先规定状态，再列出选择，写出转移，最后确定边界和计算顺序。以不限制使用次数的最少硬币数为例，`dp[x]` 表示恰好凑出 x 的最少枚数，不能凑出时使用不可达标记。

```cpp
int minCoins(const vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, amount + 1);
    dp[0] = 0;
    for (int x = 1; x <= amount; ++x) {
        for (int c : coins) {
            if (c > 0 && c <= x)
                dp[x] = min(dp[x], dp[x - c] + 1);
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}
```

前提是 amount 非负、有效硬币面值为正。先有较小金额的答案，才计算较大金额。若只允许每枚硬币使用一次，状态和循环顺序需要重新设计，不能沿用这段更新。

## 记忆化与递推

记忆化保存相同状态的递归结果，避免反复展开；自底向上递推按依赖关系逐一计算。复杂度通常可从“状态数量 × 每状态转移成本”估计，这里为 O(amount × 硬币种类数)，空间为 O(amount)。压缩空间前要先确认旧状态是否还需要保留。

常见错误是把“凑出金额 x”写成“金额不超过 x”、把不可达初始化成 0，或在边界外读取数组。先手算小表格再写循环，可以更早发现这些问题。

## 动手练习

1. 手算 coins=[2,5]、amount=7 的所有 dp 值。
2. 测试金额为 0 与无法凑出的情况。
3. 写出斐波那契记忆化与迭代两版，并比较计算同一状态的次数。
