# 动态规划设计：最长递增子序列

## 学习目标

区分子序列与子数组，推导以某个位置结尾的状态，并理解二分优化。

## 让当前元素必定出现在状态末尾

子序列保持相对顺序，但不要求连续。定义 dp[i] 为“以 a[i] 结尾的严格递增子序列最大长度”，每个元素单独构成长度 1。枚举之前的 j，如果 a[j]<a[i]，就能把 a[i] 接在对应序列之后。

```cpp
int lis(const vector<int>& a) {
    vector<int> dp(a.size(), 1);
    int best = 0;
    for (int i = 0; i < (int)a.size(); ++i) {
        for (int j = 0; j < i; ++j)
            if (a[j] < a[i]) dp[i] = max(dp[i], dp[j] + 1);
        best = max(best, dp[i]);
    }
    return best;
}
```

答案取所有末尾状态的最大值，不能直接返回最后一个 dp。时间 O(n²)，空间 O(n)，空数组返回 0。重复值不满足严格递增条件，不能使用 <= 代替 <。

## 二分维护最小结尾

优化版维护 tails[len-1]：长度为 len 的递增子序列能取得的最小结尾。对新值寻找第一个不小于它的位置并替换，若不存在则追加。更小的结尾更有利于接上未来元素，tails 的长度就是答案，时间 O(n log n)。

tails 的值不一定构成实际出现在原数组里的某条最优子序列；恢复具体序列需要记录前驱和索引。推广到二维嵌套问题时还要正确排序，尤其要处理第一维相等的对象，不能直接对两维同时升序后求严格 LIS。

## 动手练习

1. 对 [3,1,2,2,4] 手算 dp 和 tails。
2. 测试全递减、全相等和空数组。
3. 修改算法返回一条实际递增子序列，说明需要增加哪些前驱信息。
