# 知序洛谷提交桥接

Chrome/Edge Manifest V3 插件。插件使用用户当前浏览器中的洛谷登录状态，洛谷账号密码和 Cookie 不会传给知序服务器。

## 安装

1. 在洛谷模式的比赛题目工作区打开配置教程，下载 ZIP 并解压到一个固定目录；安装后不要移动或删除该目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中解压后的 `browser-extension` 文件夹。
4. 插件 ZIP 已由管理员配置知序网站来源；安装时按浏览器提示允许访问该站点，无需填写地址。
5. 刷新知序页面，在同一浏览器登录 `https://www.luogu.com.cn` 并保持洛谷页面打开。
6. 回到比赛题目工作区，点击“检测洛谷登录状态”；显示已连接后开始答题。插件通过已有的洛谷登录标签提交，不会自动打开或切换到题目页。若洛谷要求图形验证码，知序会显示验证码图片和输入框；答案仅由浏览器发回洛谷。输入错误时显示新图片，取消后可重新提交。遇滑块等交互验证或图片无法获取时，会说明需要在洛谷页面完成验证，不会自动跳转。

管理员修改网站来源后，用户需要下载新版插件 ZIP，在扩展程序管理页重新加载已解压插件。

知序检测到插件版本较旧时会自动打开本教程；下载新版 ZIP 后，在浏览器扩展程序管理页点击插件的刷新按钮，再刷新知序页面。当前桥接扩展最低版本为 `1.1.5`。

洛谷拒绝自动提交时，错误会包含 HTTP 状态码和洛谷错误码（如果接口有返回）。可在 `chrome://extensions` 中打开此插件的 Service Worker 检查视图，查看 `[SCU Luogu bridge] submission rejected` 诊断日志。日志只包含题号、状态码、错误码和错误类别，不包含代码、Cookie 或 CSRF 令牌。

每次提交由用户在本站点击后发起，代码和用户输入的验证码经浏览器发送给洛谷。验证码图片仅从洛谷加载到本站页面内存，不上传至本站服务器；插件不导出、不保存、不上传 Cookie。插件使用已登录洛谷标签页的 CSRF 令牌向洛谷提交接口发请求，不会新开原题页或切换当前标签。洛谷返回逐测试点明细时，提交记录显示 AC、WA、TLE 等判定和通过数；不会显示隐藏测试输入。

插件使用洛谷网站当前的页面提交接口，而非官方 OpenApp 评测 API。提交请求沿用洛谷页面字段 `code`、`lang`、`enableO2` 和 `captcha`，并从已登录页面读取 CSRF token。洛谷可能要求 Cloudflare 或其他安全验证；插件不会尝试绕过验证，也不会自动导航，页面接口可能随平台改版失效。正式、稳定接入应申请洛谷开放平台 OpenApp Token，并按其异步评测 API 接入；该接口与用户个人登录态桥接是两种不同方案。

代码工作区默认使用 C++11，也支持 C、Python 3、Java 和 Go。当前语言编号分别为 4、2、7、8、14，按洛谷 `/_lfe/config` 的 `CodeLanguage` 核对；成功响应读取顶层 `rid`。提交及隐藏测试评测由洛谷完成，管理员通过题目搜索导入公开题面和样例。协议依据、VJ 源码对比和复测方式见 [提交桥接排查说明](../docs/luogu-bridge.md)。
