# 二叉树练习导读

## 学习目标

把二叉树练习分为遍历、分解、后序和层序，建立复盘顺序。

## 用同一棵树练不同问题

先在一棵小树上完成节点计数、最大深度、路径记录和逐层访问。每道题先写函数含义，再选择使用外部状态还是子树返回值，不要一开始就为了套模板而增加全局变量。

遍历型题目关注访问到节点时做什么，例如记录当前路径；分解型题目关注左右子树返回什么，例如返回高度或是否满足条件。依赖两侧计算结果的题通常在后序组合；逐层输出或无权最短距离适合显式队列。

## 统一复盘表

| 内容 | 需要写下的答案 |
| --- | --- |
| 递归函数 | 参数与返回值各代表什么 |
| 空节点 | 返回什么，是否影响最大/最小值 |
| 状态 | 哪些是局部变量，哪些跨分支共享 |
| 恢复 | 返回时是否需要撤销路径 |
| 复杂度 | 节点访问次数与最大栈深 |

本课作为练习导览，不引入原站需要会员的后续习题正文。可以先用自己构造的小树练习，再前往原文查看公开介绍；需要更多练习时选择能够公开访问的题目。

每次完成后用空树、单节点、链状树和左右不对称树测试。仅在完全对称的小树上通过样例，不能说明递归返回和连接方向都正确。

## 动手练习

1. 为同一棵树分别记录前序、后序和层序结果。
2. 用分解方式求高度，再用带深度参数的遍历方式求一次。
3. 任选一次错解，填写复盘表并构造最小反例。
