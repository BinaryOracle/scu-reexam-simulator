# 如何高效寻找素数

## 学习目标

用埃氏筛批量统计素数，解释从平方开始标记及区间端点。

## 合数一定有较小因子

若一个数不是素数，它可以分解为两个不小于 2 的因子，其中至少一个不超过其平方根。因此扫描到 i 时，只需要在 i 仍是素数的情况下标记其倍数；从 i² 开始即可，因为更小的倍数已经被更小因子处理。

```cpp
int countPrimesBelow(int n) {
    if (n <= 2) return 0;
    vector<bool> prime(n, true);
    prime[0] = prime[1] = false;
    for (int i = 2; 1LL * i * i < n; ++i) {
        if (!prime[i]) continue;
        for (long long j = 1LL * i * i; j < n; j += i)
            prime[(int)j] = false;
    }
    int total = 0;
    for (int i = 2; i < n; ++i) if (prime[i]) ++total;
    return total;
}
```

这段代码统计严格小于 n 的素数，n 本身不计入。若题目要求不超过 n，就要把分配大小和所有循环端点一起调整，而不是只修改最终计数循环。

经典埃氏筛时间约 O(n log log n)，空间 O(n)。`i*i` 使用更宽类型避免溢出；n 很大时内存也可能成为瓶颈，不能只检查循环速度。单个整数判素数与批量统计是不同场景，不必为一次很大的单点判断分配同样规模的数组。

1 不是素数，0 与负数也不属于素数。把这些边界在初始化时排除，比在最后遍历时补丁式修正更清晰。
