# 双指针技巧秒杀七道数组题目

## 学习目标

区分快慢指针与左右指针，解释原地修改、搜索和回文检查的推进条件。

## 快慢指针：读取位置与写入位置

过滤数组时，快指针逐个读取输入，慢指针指向下一个保留位置。下面把目标值移除，返回有效前缀的长度，后面的旧数据不属于答案：

```cpp
int removeValue(vector<int>& values, int target) {
    int write = 0;
    for (int read = 0; read < (int)values.size(); ++read) {
        if (values[read] != target) values[write++] = values[read];
    }
    return write;
}
```

不变量是 `[0, write)` 始终保存已经读取部分中需要保留的值。写指针不会超过读指针，因此覆盖旧位置不会损坏尚未读取的数据。

## 左右指针：借助条件缩小范围

有序数组两数之和中，小于目标就增大左端，大于目标就缩小右端；有序性保证丢弃的配对不可能产生答案。回文检查则比较两端字符，相同后同时向中心移动。反转数组也是两端交换，但遇到不同时不应提前终止。

滑动窗口同样使用两个位置，但主要维护一个连续区间，并根据区间条件决定缩放。不要看到“数组”就套用双指针：如果没有有序性、可维护的窗口条件或明确读写关系，指针移动可能漏解。

练习时逐步写出指针区间的含义，并检查空数组、重复值和只有一个元素时的循环条件。

## 动手练习

1. 为示例输入 [2,1,2,3]、target=2 记录每次 read/write。
2. 用 [1,3,4,7] 寻找和为 8 的两个数，解释每次移动。
3. 写出回文检查和原地反转两个函数，比较终止条件。
