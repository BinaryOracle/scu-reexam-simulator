# 算法就像搭乐高：手撸 LRU 算法

## 学习目标

组合哈希表和双向链表，在常数期望时间内定位并更新最近使用顺序。

## 一个结构定位，一个结构维护顺序

LRU 淘汰最近最少使用的键。哈希表保存 key 到链表节点的位置，双向链表保存使用次序，头部表示最新使用，尾部表示最久未用。命中读取或更新值时，把已有节点移动到头部；新建后若超容量，删除尾节点并同步删除哈希记录。

```text
get(key):
    若表中没有 key，返回未命中
    将对应节点移动到头部
    返回节点的 value
put(key, value):
    若已存在，更新值并移动到头部
    否则在头部新增节点并登记表
    若数量超过 capacity，删除尾节点并移除对应 key
```

C++ 可以用 `list<pair<int,int>>` 和 `unordered_map<int, list<...>::iterator>` 组合，移动节点使用 splice，避免先删除再使用已经失效的迭代器。自己实现链表时，使用头尾哑节点能统一插入和删除边界。

## 常见失配

只移动节点却不更新映射、删除尾节点后仍保留 key、读取也被算作“未使用”、容量为 0 时继续返回刚插入数据，都可能导致错误。检查表中数量、真实链表节点数和容量约束始终一致。

哈希操作按平均或期望 O(1) 分析，链表定位后的插入与删除 O(1)，空间为 O(capacity)。若只用单链表却没有前驱索引，就不能保证任意已知节点的删除仍为常数成本。

## 动手练习

1. 容量为 2，依次 put(1)、put(2)、get(1)、put(3)，判断被淘汰的键。
2. 实现更新已有 key 的情况，确认节点数不增加。
3. 测试容量 0、容量 1 和连续未命中，检查映射与链表一致。
