# 课程管理与学习体验重设计

## 产品目标

让管理员可以快速创建、整理、预览和发布课程，让学员能通过课程简介、封面和目录判断课程内容，并在学习页顺畅切换章节与课时。后台管理与学员课程入口职责分明，页面保留现有课程权限、直播主持人权限和课时数据。

本期继续使用现有课程内容类型：录播视频、Markdown 课程正文、可下载附件和直播。一个课时可以包含多种内容。课程简介和课时说明均支持 Markdown。

## 后台信息架构

课程管理是管理员专属工作区，不显示“我的课程”或“课程广场”等学员入口。进入工作区后，管理员首先看到课程列表；创建或编辑课程时，使用连续的三个步骤：“基本信息”“课程内容”“学员与发布”。用户可从任一步骤返回其他步骤，未完成的课程可以作为草稿保存。

课程列表顶部提供课程数量、关键词搜索、草稿/已发布/已归档筛选和新建课程操作。桌面端每门课程占一行，显示封面、标题、纯文本简介摘要、发布状态、访问方式、章节数和课时数；窄屏端改为纵向摘要行。编辑课程是主要操作；预览、归档和删除放入清晰的次级操作菜单。删除继续显示确认对话框，并说明关联内容会一并移除。

管理员工作区使用独立页面标题和课程管理导航。列表、基本信息表单、章节课时清单和发布设置共享同一内容宽度、间距和按钮层级；管理页面不复用学员端课程卡片导航。

## 课程基本信息

课程信息包括课程名称、Markdown 简介、封面和加入方式。管理员可以上传图片，或从系统预设封面中选择一个；当前课程只使用一个已选封面。图片上传显示裁切后的预览，未选择自定义图片时显示所选预设。课程简介提供 Markdown 编辑和预览；课程列表摘要从 Markdown 内容提取纯文本并截断。

学员公开页面安全渲染 Markdown。渲染器允许常见正文格式、链接、列表、引用、表格和代码块；移除脚本、内联事件处理器及危险协议链接。课时说明遵循相同规则，课程目录和列表只显示纯文本摘要。

## 课程内容管理

课程内容页用章节分组的连续清单展示内容，不使用章节卡片中再套课时卡片的视觉结构。章节标题、课时数量和章节操作位于同一行；章节下的课时按顺序排列，并显示课时名称、说明摘要、内容类型和内容数量。管理员可以添加章节、添加或排序课时、预览课时、编辑课时说明和管理课时内容。删除章节或课时前执行关联内容检查并显示确认说明。

添加录播、Markdown 正文、附件或直播的交互沿用现有课程 API 与直播服务。一个课时可以组合多种内容，内容顺序由管理员编排并在学员端保持一致。Markdown 正文使用编辑/预览方式；附件保留私有下载权限；直播继续由现有直播模块管理。

## 学员课程体验

课程广场和我的课程卡片显示封面、名称、纯文本简介摘要、主讲人、课时数、访问状态及学习进度。课程详情使用封面和课程标题构成页面主视觉；简介安全渲染 Markdown；目录按章节列出课时名称和内容类型。未加入课程的公开预览提供明确的加入入口，已加入课程显示继续学习或开始学习。

学习页采用目录与内容两栏：章节/课时目录固定在左侧，当前课时内容在主体区按管理员编排顺序显示；视频支持续播，附件提供查看或下载，上一课/下一课在固定位置。窄屏下目录折叠为课时选择器，内容区优先显示。

## 视觉与交互

沿用课程区现有的暖白背景、深色正文、砖红品牌强调色和深绿进度色。使用稳定的标题层级、留白和细分隔线组织内容；减少大色块、重复标题、无意义英文装饰和层层嵌套卡片。主要按钮始终突出当前任务：新建课程、继续编辑、保存草稿、发布、加入课程或继续学习。次要和危险操作使用一致的菜单与确认样式。

桌面端课程列表使用宽屏信息行和清晰列对齐；窄屏端转为单列摘要，筛选控件可换行，关键操作保留可见。所有可操作控件提供键盘焦点样式；加载、空列表、筛选无结果、保存中、保存失败、发布条件不足和权限拒绝均显示明确反馈。

## 数据、安全与兼容

- 保持现有课程、章节、课时、资源、报名、直播和学习进度数据；不重建 LiveKit 房间，不改变直播会话 ID。
- 继续由服务端校验课程管理权限、名单访问权、公开加入状态、附件下载和视频播放权限。
- 上传封面采用私有存储和随机服务端文件名，校验图片类型、文件大小及解码结果；不能将原文件名用作磁盘路径。
- Markdown 输入以原文保存，渲染结果使用允许列表清理；不得信任客户端提交的渲染 HTML。
- 课程简介、封面和课时内容更新失败时保留编辑内容并提供重试反馈。
- 管理端重设计不新增全局教师角色，也不改变现有课程创建、发布、归档、删除的授权规则。

## 验收标准

- 管理课程工作区中没有“我的课程”或“课程广场”学员导航。
- 管理员可以搜索课程、筛选状态、创建草稿、编辑课程信息、管理章节/课时并完成发布；从任意编辑步骤都能返回或切换步骤。
- 课程封面可以使用上传图片或预设样式；列表、公开详情和学习页能显示所选封面。
- 课程简介与课时说明支持 Markdown 编辑和预览；学员端可读地显示正文，危险 HTML 不执行；摘要只显示纯文本。
- 含直播、录播、Markdown 正文和附件的混合课时能按管理顺序展示，原有访问控制、播放、下载和直播功能保持有效。
- 删除课程、章节或课时时，确认内容说明实际影响，取消操作不会修改数据。
- 桌面与窄屏下主要信息、状态和操作有清晰层级；无内容被遮挡、控件重叠或横向溢出。

## 验证范围

服务端测试覆盖封面上传类型和权限、Markdown 原文存储与安全渲染、课程摘要提取、章节/课时内容顺序、删除影响及现有课程访问控制。前端测试覆盖课程列表搜索筛选、步骤导航、封面上传/预设选择、Markdown 编辑/预览、空状态和错误恢复。浏览器验收覆盖管理员列表和编辑器、学员课程广场、课程详情及课时学习页的桌面与窄屏流程。

## 不在本期范围

不新增第三方课程平台接入、课程评论、测验、证书、推荐算法、支付或全局教师角色；不改写直播音视频、录制服务和直播课堂交互。
