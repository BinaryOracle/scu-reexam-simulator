# 知序多平台评测提交桥接

Chrome/Edge Manifest V3 插件，支持洛谷和 LeetCode 中国区。LeetCode 的搜索、题面导入和提交目标固定为 `leetcode.cn`，不支持 `leetcode.com`。插件在当前浏览器使用用户已登录的平台标签页提交代码；账号密码和 Cookie 不会传给知序服务器。

## 安装

1. 在上机比赛或算法练习页面打开配置教程，下载 ZIP 并解压到一个固定目录；安装后不要移动或删除该目录。
2. 打开 `chrome://extensions` 或 `edge://extensions`，启用开发者模式。
3. 选择“加载已解压的扩展程序”，选中解压后的 `browser-extension` 文件夹。
4. 插件 ZIP 已由管理员配置知序网站来源；安装时按浏览器提示允许访问该站点，无需填写地址。
5. 刷新知序页面，在同一浏览器登录本题对应的平台：洛谷 `https://www.luogu.com.cn` 或 LeetCode 中国区 `https://leetcode.cn`，并保持已登录标签页打开。
6. 回到题目工作区，点击对应平台的“检测登录状态”；显示已连接后开始答题。插件只在相同平台已登录的标签页中提交，不会自动打开或切换到原题页。LeetCode 题目搜索、导入和提交均使用中国区站点。若洛谷要求图形验证码，知序会显示验证码图片和输入框；答案仅由浏览器发回洛谷。遇滑块等交互验证或图片无法获取时，会提示用户在洛谷页面完成验证，不会自动绕过。

管理员修改网站来源后，用户需要下载新版插件 ZIP，在扩展程序管理页重新加载已解压插件。

知序检测到插件版本较旧时会自动打开本教程；下载新版 ZIP 后，在浏览器扩展程序管理页点击插件的刷新按钮，再刷新知序页面。当前多平台桥接扩展最低版本为 `1.3.0`。

洛谷拒绝自动提交时，错误会包含 HTTP 状态码和洛谷错误码（如果接口有返回）。可在 `chrome://extensions` 中打开此插件的 Service Worker 检查视图，查看 `[SCU Luogu bridge] submission rejected` 诊断日志。日志只包含题号、状态码、错误码和错误类别，不包含代码、Cookie 或 CSRF 令牌。

每次提交由用户在本站点击后发起。代码经浏览器发送到当前题目的来源平台；插件不导出、不保存、不上传 Cookie。LeetCode 使用已登录 `leetcode.cn` 标签页内的 CSRF 令牌提交，并通过该站点的提交状态接口读取判定。洛谷验证码图片仅从洛谷加载到本站页面内存，不上传至本站服务器，答案仅由浏览器发回洛谷。平台返回测试点信息时，提交记录显示判定与通过数；不会显示隐藏测试输入。

插件使用平台网页当前的提交和状态查询接口，不是平台官方服务 API。LeetCode 题目数据来自 `leetcode.cn`；插件在该站登录页面内提交并轮询判定。洛谷提交请求沿用其页面字段 `code`、`lang`、`enableO2` 和 `captcha`，并从已登录页面读取 CSRF token。平台可能要求安全验证；插件不会绕过验证或自动导航。由于依赖网站页面接口，平台改版后可能需要更新插件。本站接收到的浏览器判定未由服务端向平台复核，不应作为有防作弊要求的正式成绩凭证。

代码工作区默认使用 C++11。洛谷支持 C++11、C、Python 3、Java 和 Go；LeetCode 中国区根据导入题目的官方模板提供 C++、C、Python 3。每道题的提交和结果查询根据 `remote_platform` 分派。管理员可在比赛中按题混合平台；普通用户可导入 LeetCode 中国区题目并保存为私人练习。洛谷当前协议依据、VJ 源码对比和复测方式见 [提交桥接排查说明](../docs/luogu-bridge.md)。
