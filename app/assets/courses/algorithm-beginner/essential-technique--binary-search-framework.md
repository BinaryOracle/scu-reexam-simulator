# 二分搜索算法核心代码模板

## 学习目标

用闭区间不变量写出普通查找及左右边界，避免混淆相等时的处理。

## 每次循环都缩小仍可能含答案的区间

闭区间 `[left,right]` 以 left=0、right=n-1 初始化，left<=right 时仍有候选元素。比较后如果确定 mid 不是目标，就排除 mid，使用 mid+1 或 mid-1，防止区间停滞。

```cpp
int findIndex(const vector<int>& a, int target) {
    int left = 0, right = (int)a.size() - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] < target) left = mid + 1;
        else if (a[mid] > target) right = mid - 1;
        else return mid;
    }
    return -1;
}
```

前提是输入升序。空数组右端为 -1，循环自然跳过。写成 size()-1 后再进行无符号减法可能下溢，因此先转换或使用其他安全索引方式。

## 查找一个与查找边界不同

存在重复值时，直接返回 mid 不能保证最左或最右。找左边界遇到相等时记录候选并继续向左收缩；找右边界则继续向右。若返回插入位置，还要区分“不小于目标的第一个位置”和“目标真的存在”，读取 a[index] 前检查范围。

每次至少丢弃一半候选，查找时间 O(log n)，迭代额外空间 O(1)。但排序成本不包含在查找本身；若输入未排序，不能直接使用模板，更不能忽略排序改变原索引的影响。

## 动手练习

1. 对 [1,2,2,2,5] 查找 2，分别求任意、最左、最右位置。
2. 测试空数组、单个元素和目标大于全部元素。
3. 解释为什么闭区间中的循环条件是 <=，以及相等时继续收缩的方向。
