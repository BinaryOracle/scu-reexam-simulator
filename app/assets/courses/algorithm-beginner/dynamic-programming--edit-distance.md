# 经典动态规划：编辑距离

## 学习目标

为两个前缀定义编辑距离，正确处理插入、删除和替换三个选择。

## 状态对应两个前缀

令 dp[i][j] 为 a 的前 i 个字符转换成 b 的前 j 个字符所需的最少编辑次数。空串转换需要全部插入或删除，因此 dp[0][j]=j，dp[i][0]=i。字符相同可直接继承对角线，否则在插入、删除、替换三种操作中取最小再加 1。

```cpp
int editDistance(const string& a, const string& b) {
    int m = (int)a.size(), n = (int)b.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1));
    for (int i = 0; i <= m; ++i) dp[i][0] = i;
    for (int j = 0; j <= n; ++j) dp[0][j] = j;
    for (int i = 1; i <= m; ++i)
        for (int j = 1; j <= n; ++j)
            dp[i][j] = a[i - 1] == b[j - 1] ? dp[i - 1][j - 1]
                : 1 + min(dp[i - 1][j - 1], min(dp[i - 1][j], dp[i][j - 1]));
    return dp[m][n];
}
```

这对应单位成本、按字节字符的标准编辑距离，不包含交换两个字符的额外操作。若题目允许不同操作成本或要求按 Unicode 字符处理，需要先调整状态输入或转移。

时间 O(mn)，二维表空间 O(mn)。只求距离可以用滚动行压缩空间，但保留左上角旧值；若还要恢复具体编辑序列，通常需存储完整路径信息或采用其他恢复方法，不能仅凭最终一个数逆推出全部过程。
