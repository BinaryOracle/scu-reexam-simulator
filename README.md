# 四川大学计算机复试模拟系统 V1.0

独立部署的学校/培训机构模拟考试系统，提供模拟面试录音与 AI 点评，以及参考 VJudge/洛谷竞赛流程的限时 OJ。账号区分普通用户、管理员与超级管理员，无教师角色。此项目不依赖 DeepSeek Harness。使用 Python 3.12、SQLite；洛谷桥接支持 C++11、C、Python 3、Java 和 Go，旧版本地 Docker 比赛仍使用 Python 3 评测。

算法带刷另提供八阶段、430 道题的题单、已完成/未通过筛选、用户收藏、每日一题打卡、私人投稿与审核奖励；提交结果统一展示在提交记录面板。C/C++11/Python 3 公开样例采用受限 Docker 评测。题库来源、构建和奖励边界见[算法带刷说明](docs/coding-catalog.md)。

直播课堂 V1 复用现有账号，提供课程与多课次、课程主持人授权、私有资料、评论举手、单人共享与服务端录播。音视频需要独立部署 LiveKit，录制另需 Egress、Redis 和共享私有存储；未配置时明确提示服务未就绪。使用、配置与上线验收见 [直播课堂部署与使用](docs/live-classroom.md)。Mac 本机部署使用 `.venv/bin/python scripts/live_local.py start`，已完成双人真实音视频、互动、录制与私有回放验证；尚未完成 50 人负载验收。

## 热点趋势

登录后可在「热点趋势」查看当日、当周、当月和当年的 AI 前沿摘要，正文采用 Markdown 展示，并附带 Google News、arXiv 与 GitHub 的原始检索来源。后台使用 Qwen `qwen3.7-plus` 自动生成内容，每天北京时间 06:00 刷新一次，应用启动时也立即刷新；失败周期每 15 分钟重试。每个周期只保留当前报告，新结果覆盖旧报告。管理员可编辑当前展示内容或手动刷新所选周期，不提供历史趋势归档。

趋势检索使用公开平台接口，不代表完整互联网覆盖；网络不可用或来源没有结果时不会生成无来源摘要。`[trends]` 可设置模型、检索数、网络超时和自动刷新时间；模型密钥沿用服务端 `[ai]` 的 `api_key` / `api_key_env`，默认环境变量为 `DASHSCOPE_API_KEY`。SQLite schema 版本为 34，升级时每类趋势只保留最新一条记录。

## 快速启动

从环境准备到应用、Docker 评测和直播课堂的完整部署流程见[系统部署手册](docs/deployment.md)。

```sh
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.toml config.toml
sh scripts/prepare_judge.sh
.venv/bin/python -m scripts.create_user candidate
.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
```

需要启用 Mac 本机直播与录播时，先运行 `.venv/bin/python scripts/live_local.py start`；它会部署媒体服务、配置私有密钥文件并启动网站。首次准备后直接重启 Uvicorn 也能读取直播密钥，详见 [直播部署说明](docs/live-classroom.md)。

空数据库首次启动会创建默认管理员：用户名 `root`，密码 `root`，并开通全部系统。以后启动不会重置已有账号或密码。命令行创建其他用户时交互输入密码。`scripts/prepare_judge.sh` 会准备包含 C++11、C 和 Python 3 的隔离评测镜像；需要先启动 Docker Desktop。前台访问 http://127.0.0.1:8000，后台访问 http://127.0.0.1:8000/admin。配置文件 `config.toml` 集中设置数据路径、录音与 PPT 限制、转换程序、会话时长、面试题、AI/ASR 接口、评测镜像和资源限制。也可通过 `SCU_CONFIG=/path/to/config.toml` 指定配置；密钥放在被 Git 忽略的本地配置文件或指定环境变量中，只由后端读取。

## 账号与后台管理

后台与前台共用朱红、暖米白、浅金和草木绿主题，通过 `/admin` 独立访问，前台不显示后台入口。后台提供按管理身份隔离的用户列表、搜索与启停筛选、用户名与密码重置、行内次数编辑和用户删除。超级管理员可新建「管理员」或「普通用户」；普通管理员只能创建和管理普通用户。

所有启用账号均可访问模拟面试及每日训练、算法带刷和上机比赛的首页。模拟面试由剩余次数控制，正式开始成功才扣次；每日训练与算法带刷使用同一个 `can_practice` 权限，后台用户列表和新建用户时可开通，新普通用户默认未开通，管理员默认开通。上机比赛详情、参赛和赛后回顾由每场比赛的指定用户名单控制。`is_admin` 允许管理普通用户、比赛和题库，`is_superadmin` 额外管理普通管理员及其记录。

`is_active` 控制账号启停，通过状态按钮切换；停用立即使既有会话失效，历史记录保留。密码重置同样结束该账号全部登录会话。当前管理员不能停用自己或撤销自己的管理身份；系统保留至少一个启用的管理员。

默认 root 是唯一超级管理员，身份与账号 ID 绑定，改名后仍保留。普通管理员的账号列表和复核接口均无法读取 root 或其他管理员；超级管理员可以重置自身和其他管理员的用户名、密码，并删除普通管理员。删除用户会清理其会话、面试、录音、PPT、提交和次数账本，已兑换卡密保留已使用状态和兑换用户名快照，不会再次流通。不能删除超级管理员或当前账号。

用户名通过操作列「重置用户名」修改，仅校验非空和唯一性。改名保留账号 ID、邮箱、密码、历史记录和已有会话，后续密码登录使用新用户名。

首次部署使用默认 `root / root` 登录后台。用户名和密码不设字符、长度上限或复杂度规则，均需填写，用户名保持唯一；按原文保存和匹配，不自动裁剪空格。命令行使用 `--admin` 创建普通管理员，省略时创建普通用户。

### 邮箱验证码登录

前台默认使用邮箱加 6 位验证码登录，保留账号密码切换入口。首次邮箱登录自动创建普通账号，用户名默认为完整邮箱、密码随机生成，并发放后台配置的初始体验次数；后续登录复用同一账号。后台仍使用管理员账号密码登录。管理员新建用户时可填写唯一的登录邮箱，使邮箱登录关联到该账号；不填写时继续使用用户名密码。账号列表的邮箱列仅展示地址或“未绑定”，不提供修改或解除绑定按钮；用户通过个人主页验证新邮箱后自行换绑。邮箱不会按相似用户名自动关联账号。

使用 QQ 邮箱或腾讯企业邮箱 SMTP 的配置步骤见 [邮箱登录配置](docs/email-login.md)。未配置发件邮箱及授权码时明确提示服务未就绪，不会伪报发送成功。验证码短时有效、单次使用，发送间隔、错误次数及邮箱/IP 频率均受限；账号停用同时阻止两种登录方式。

个人主页支持修改用户名、修改登录密码、验证新邮箱后变更绑定和注销当前账号；超级管理员不能自行注销。登录密码默认遮掩，点击可查看本人密码原文，再次点击或离开主页时隐藏。邮箱账号修改密码和注销需验证当前绑定邮箱，旧未绑定账号验证当前密码。个人主页提供明显的「退出登录」和卡密兑换入口，兑换使用单独输入框与按钮，错误在表单内显示；不展示固定套餐卡片或管理员内部额度。后台新增套餐只需填写金额（元，最多两位小数）与面试次数，生成、筛选及导出选项均从数据库读取。站内删除、改名、换题和结束面试使用统一对话框；离开或刷新含未保存内容的页面时，浏览器自身的防丢失确认仍保留。

## 每日训练与次数转赠

前台「每日训练」支持专业课问答、英文翻译和英文问答，提供随机训练与按顺序复习，支持全部可练题或重点回顾。默认每日完成 5 道不同题后点击签到；连续第 7、14、21 天分别新增 1、2、3 次模拟面试次数，断签重新累计且不扣回既有奖励。私人题默认仅作者可见，主动提交并经后台审核后公开。专业课和翻译保留原始资料中的参考答案，英文问答仅展示题目。

个人主页「面试次数转赠」支持指定普通用户的完整登录用户名与次数，保存双方转入/转出记录。余额更新在同一事务完成，重试不重复扣次；不允许转给自己、管理员或停用账号，不计入卡密消费金额。管理员通过原有后台次数管理调整用户额度。

使用说明、配置与数据迁移见 [每日训练与转赠](docs/daily-training.md)，资料映射见 [训练答案来源核对](docs/training-source-audit.md)。

题目审核奖励、后台图文公告和备考首页资源整理说明见 [投稿奖励、公告与备考首页](docs/contribution-rewards-announcements.md)。

备考首页从“复试准备路线”起支持后台动态编排：区块和卡片可增删、排序、隐藏，配置星级与跳转链接，预览后发布。配置保存在数据库，版本冲突不会覆盖其他管理员的修改。v28 自动迁移已有用户练习权限与旧比赛访问方式；完整规则见 [首页编排与练习授权](docs/home-layout-access.md)。

## V1.0 能力

- 考生写题工作区采用左侧题面、右上代码、右下样例/提交记录布局，三个区域独立滚动；拖动中间和右侧横向分隔条可调整宽高，分隔条支持方向键、Shift 加速、Home/End 和双击恢复该方向默认比例。每个区域右上角可单独放大，再次点击或按 Esc 还原，顶部「恢复布局」恢复全部默认比例。布局按用户保存在当前浏览器，切题、刷新后保留比例；放大/还原保持编辑器节点、光标、代码和当前结果。窄屏用「题面/代码」切换，代码与辅助区仍能上下调整；切换页签或跨越桌面断点自动退出区域放大。
- 比赛详情与写题工作栏显示每秒更新的倒计时和已用时间进度条，最后五分钟以红色提示。详情页可点击任意题目直接进入对应工作区；未开赛时普通用户不能打开题目，结束后可查看题目但不能提交。得分制排行榜按每题最佳结果累计分数；洛谷逐测试点明细可用时，部分分按题目总分乘以通过测试点比例并向上取整。排行榜突出前三名、当前用户和得分，并展示每题得分与提交次数，支持手动刷新；窄屏可横向滚动查看完整排名。
- 管理员创建比赛时通过洛谷题号或关键词搜索并选择至少一道题，系统自动导入题面、资源限制和可公开样例；比赛创建后可修改名称、起止时间和题目，已有提交的题目不能被移除，后台也可从洛谷刷新旧题样例。比赛列表进入独立信息页，再进入题目工作区；题面按 Markdown 结构展示并由本地 KaTeX 渲染公式，不依赖外部 CDN。题目没有公开样例时明确提示，不伪造空样例。删除比赛会清理关联题目及提交记录。洛谷桥接使用浏览器插件提交，用户可在上机页下载插件、按教程配置并检查当前登录状态，本站保存提交记录及浏览器同步的远端评测状态。
- 历史 Docker 比赛仍由隔离容器评测；新建比赛界面只提供洛谷桥接。Docker 评测关闭网络、使用只读根文件系统、删除 Linux capabilities，并限制进程、内存和 CPU。洛谷插件将 C++11、C、Python 3、Java、Go 映射为洛谷对应语言后提交；洛谷登录态只由浏览器持有，插件不向本站传输密码或 Cookie。洛谷状态来自用户浏览器插件读取后回传，本站不独立认证远端结果，因此不应将其作为正式排名或成绩凭证；管理员和用户均可打开洛谷记录复核。洛谷页面接口可能变化；图形验证码在本站输入，交互验证或安全限制交由洛谷页面处理，详见 [提交桥接](docs/luogu-bridge.md)。使用前应确认平台规则允许提交桥接。
- 开始新面试后先进入准备页，选择自己的复试 PPT（`.ppt` / `.pptx` / `.pdf`）并检测麦克风；文件只暂存在当前页面。点击底部「开始模拟面试」后才上传和转换 PPT、创建面试记录、展示幻灯片、启动严格十分钟倒计时并自动全程录音；切换环节持续录制。返回记录首页或文件转换失败都不会留下空记录。作答时不展示实时字幕，语音在后台转写并保存；完成自我介绍自动保存并进入下一环节。AI 只在最后专家问答中提问和生成整场点评，上机不接入 AI。
- 面试流程为 PPT 自我介绍、专业课问答、英文段落翻译、英文口语问答和 AI 专家追问。专业课从数据结构、操作系统、计算机网络卡片中选择，最多换到另一学科一次，复盘保留换题前后题目；翻译与口语环节随机抽题并固定在本场记录。后台「面试题库」提供题目增删改查和启停管理。题目从 JSON 首次导入 SQLite，运行期间以数据库为准；目前包含 96 道专业题、31 段英文翻译题和 53 道英文口语题。
- 面试使用接近全屏的沉浸布局，顶部居中显示紧凑倒计时，最后一分钟变红，PPT 全屏仍可见。正式开始后完全隐藏主导航，PPT 放大展示并支持上下方向键翻页，专家环节在桌面采用左侧 PPT、右侧问题的布局；作答中不显示实时字幕、普通录音面板和回答回顾；环节列表默认收在左边缘，悬停或点击时展开，支持键盘开关及 Escape 收起。结束按钮位于环节底部、下一步操作之后；到时或主动结束自动停止录音并保存，随后回到 001 环节复盘。右上角醒目按钮返回记录，返回后恢复导航并清理详情按钮和计时器；开始新面试仅在记录首页显示。英文问答的下一环节直接进入专家问答，专家页右下角结束面试、下方居中生成整场点评。结束、超时和返回记录都不会自动生成点评，只有专家页主动确认生成点评才调用 AI。生成点评时只禁用重复生成，允许切换环节复盘和返回记录，结果自动保存。
- 面试记录首页仅展示已完成面试及对应统计，支持重命名和删除；删除前需确认，并清理该场回答、录音及 PPT 文件。当前场次刷新后自动恢复到面试页，过期场次结束归档。结束后在页面底部逐环节回顾完整回答并回放录音，切换环节保持同一个全程录音播放器及播放进度；回放使用独立进度拖动条、音量调节，完整回答展开后提供更宽、更高的阅读区。管理员后台复核保持只读。
- 录音默认每 15 秒备份，结束或截止后有 120 秒最终音频上传窗口，不接受迟到答案。上传失败可重试或下载到本机。刷新后已上传声音保留，需手动恢复录音形成新片段，倒计时不会重置。实时识别依赖配置的 ASR 或浏览器语音服务，无法识别时会明确提示，原始录音仍保存；录音与计时细节见 [面试流程](docs/interview-timing.md)。
- 面试转写、录音及点评按场次保存，普通用户只能访问自己的记录；管理员在后台只读复核。会话凭证使用 Bearer token，登录密码使用 scrypt 哈希；后台点击查看原文使用单独的加密副本，密钥管理及旧账号处理见 [次数与卡密](docs/credits-and-vouchers.md)。
- 普通用户默认 1 次免费模拟面试，后台可修改新用户默认值、创建时指定或调整现有余额；管理员使用 999999 次且不扣减。正式开始成功才扣 1 次，删除记录不返还次数。点击头像进入个人主页兑换卡密并查看剩余次数、兑换记录和套餐标价累计。
- 后台「卡密与次数」动态新增和管理各金额／次数套餐，支持随机批量生成、分页筛选和一行一卡密 TXT 导出，手动上传至联动小铺售卖；个人主页提供可配置的店铺购买链接，本站不对接商城订单或支付。兑换事务保证一卡一次。详细规则与配置见 [次数与卡密](docs/credits-and-vouchers.md)。

## 界面与使用

桌面侧边导航支持收起为图标栏，并记住浏览器中的选择；窄屏可收起导航。正式面试隐藏普通工作台框架，保留左侧展开入口。面试作答区按题切换，显示 PPT 预览、字幕、已完成进度和未保存文本状态；完整回答可展开校对。自我介绍和专家问答页不显示公共模板说明，该提示仅在准备页保留。放映区可使用按钮或聚焦后按左右方向键翻页；刷新后从面试记录继续，已上传文件保留。切换环节保留当前文本草稿，刷新或退出前提醒未保存修改。新面试实时转写自动保存；手动校对可点击保存或在切换环节时保存。

页面切换会写入本站 URL hash，浏览器刷新和前进 / 后退可恢复当前主页面；比赛详情、答题工作区及当前题目也会保存在地址中。洛谷桥接状态按账号保存在浏览器本地，并在恢复洛谷答题工作区时自动向插件重新确认；本站不保存洛谷凭证。上机页将比赛列表、比赛详情和答题工作区分开展示。开始答题后进入沉浸布局，隐藏全局导航、页面标题和说明文案；单行工作栏保留比赛名称、倒计时与返回入口，题面和代码区尽量占满可视空间，洛谷连接状态与题目切换压缩为紧凑控件，样例和提交记录收在编辑器下方标签中。桌面可独立滚动题面和代码区，并用鼠标拖动或键盘方向键调整分栏；窄屏以「题面 / 代码」页签切换。题目导航显示平台题号；洛谷无公开样例时给出说明。代码草稿按账号和题目保存在当前浏览器，提交不会清除草稿。后台考务管理提供洛谷题目联想导入、比赛信息和题目编辑、题面样例刷新及比赛删除，前台不展示管理表单。

后台提交记录统一收纳在比赛信息页：点击排名中的用户名查看该用户本场全部提交，点击用户对应题目的成绩格查看其该题提交；点击比赛题目的「尝试 / 通过」查看对应记录。排名区域的「本场全部提交」始终可用，包括关闭排名的比赛。弹窗按最新提交倒序，每页 10 条；支持刷新、分页与单条代码和评测详情，手机端改为紧凑列表。题目统计仅包含普通用户，与「尝试 / 通过」弹窗一致；普通管理员仍不能访问其他管理员记录。独立后台提交总览已移除，旧地址转至比赛列表；前台保留个人提交记录。

前端为原生 ES modules，无前端打包步骤或 CDN 字体/组件依赖。KaTeX 的 JavaScript、样式和字体随本地静态资源分发。请求、共享组件、账号管理、面试、上机与入口分别位于 `app/static/`，样式颜色统一由 `style.css` 根变量管理。Qwen3-ASR-Flash 的服务端音频转换依赖 ffmpeg；Office 转 PPT 预览依赖配置的 LibreOffice。

## 默认 PPT 模板

面试准备页提供默认「附件2：研究生复试-个人情况简介模板（统考生）」原始 PPTX 下载及[复试官网](https://cs.scu.edu.cn/info/1266/19768.htm)链接。界面明确标注「2026 年复试 PPT 模板文件，最新版请从复试官网下载」。模板用于参考，填写完成后仍需上传自己的演示文件；不会将公共模板当作用户已提交的 PPT，上传后显示文件信息，点击开始面试后展示个人文件。

`[presentation_template]` 集中配置模板目录、显示年份、下载文件名与官网地址。`app/assets/reexam-2026/` 保存原始 `template.pptx`、6 张静态预览及页数 `manifest.json`，随代码分发，展示及下载不依赖转换服务或官网在线状态。更新模板时应一起替换原文件、全部预览图片、页数和配置年份，下载文件保持原始字节内容。公共模板通过 `/api/presentation-template` 及其下载、预览接口访问，与用户私有文件分开存储。

## PPT 转换与存储

安装 [LibreOffice](https://www.libreoffice.org/download/download-libreoffice/)，将 `soffice` 加入服务进程的 PATH，或将 `[presentation].converter` 设置为可执行文件绝对路径。macOS 常见路径为 `/Applications/LibreOffice.app/Contents/MacOS/soffice`。Python 依赖中的 PyMuPDF 负责 PDF 检查与预览渲染；服务端不依赖 PowerPoint、Keynote 或第三方在线查看服务。转换程序未安装时可直接上传从 PPT 导出的 PDF。

`[presentation]` 统一配置私有文件目录 `directory`、上传上限 `max_mb`（默认 25）、页数 `max_pages`（默认 60）、转换超时 `timeout_seconds`（默认 60）和预览最长边像素 `render_size`（默认 1440）。每次 Office 转换使用单独的 LibreOffice 用户目录。幻灯片保存为静态图片，动画、嵌入音视频及演讲者备注不参与放映，字体替换可能影响排版。

`fontconfig_file` 默认指向 `config/fonts.conf`，相对路径按项目根目录解析，仅在转换子进程中设置 `FONTCONFIG_FILE`，不修改系统字体配置。该文件包含 macOS/Linux 字体目录及宋体、黑体、微软雅黑等中文字体的替代规则。服务器必须安装中文字体：macOS 使用系统宋体/黑体，Debian/Ubuntu 可安装 `fonts-noto-cjk`；项目不附带系统字体。需要特定字体时安装有权使用的字体并调整此配置；设置为空字符串则使用转换进程继承的字体配置。非空路径不存在时直接报告配置错误。

字体配置修复后，已有预览不会自动变化。维护时先停止服务并备份数据库，再使用保留的原始 PPT 在新目录重新转换，仅更新 `presentations.directory` 和 `pages`，保留旧目录用于回退。不要通过重新上传接口修复预览，该接口会重置自我介绍回答。

原文件和预览均保存在私有数据目录，通过带身份认证的接口读取预览，不挂载为静态资源；普通用户只能读自己的 PPT，后台管理员只读查看。替换 PPT 会清空该环节的录音关联和回答文字；转换失败保持旧文件与回答可用。历史文件版本暂不自动清理，需将整个演示目录与数据库、录音一起备份，并定期关注磁盘容量。

## 外部服务与规则

AI 接口兼容 OpenAI Chat Completions 格式。语音识别使用阿里云 DashScope OpenAI 兼容音频接口，模型名 `qwen3-asr-flash`，发送 WAV Data URI；需要配置 DashScope URL 和服务端凭据。未配置 ASR 时尝试浏览器实时识别；不可用时保留原始录音供复盘，作答过程中不展示字幕；未配置 AI 时不会产生虚构追问或点评，接口返回清晰错误。

超级管理员可在后台「系统设置 → 大模型与语音服务」配置面试多模态模型、ASR、TTS 与热点趋势模型的接口地址、模型名和 API Key。设置保存在 `app_settings`，API Key 使用 `security.password_key_file` 指定的 Fernet 密钥加密，接口与页面只返回配置状态和来源，不回显密钥。新设置对后续请求立即生效；模型服务密钥留空保持原值，勾选清除后回退到本地配置或环境变量。趋势模型未设置独立密钥时继承面试多模态服务的密钥。恢复数据库时必须同时恢复配套密钥文件。

正式进入每个环节时自动播报环节名称，专家环节提示“专家给出的问题为”后继续播报题目。录音保持连续，播报期间暂停实时转写，建议佩戴耳机；结束或切换环节会取消旧播报，回顾记录时不自动发声。浏览器阻止自动播放时可点击“环节播报”重试。环节提示和专家问题播报使用百炼 `qwen-audio-3.1-tts-plus`。北京地域公共接口 `https://dashscope.aliyuncs.com/api/v1` 已通过真实调用验证，配置在 `[tts].base_url`，也可使用同地域的 Workspace 专属地址 `https://<WorkspaceId>.cn-beijing.maas.aliyuncs.com/api/v1`。请求路径由系统追加为 `/services/audio/tts/SpeechSynthesizer`；默认音色为该模型支持的 `longanhuan_v3.1`，输出 WAV/24 kHz。使用具有该模型访问权限的同地域 API Key，通过 `DASHSCOPE_API_KEY` 环境变量或服务端配置读取。具体字段和音色以[百炼 TTS API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)及[官方音色表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)为准。语音失败不阻断文字提问和点评。

VJudge 比赛页需登录后才能核实题目，本系统不抓取或复制其受限内容。管理员应仅录入有权使用的题目。比赛时长、试题、语言和评分规则由机构确认后配置；示例面试问题和计时并非四川大学官方规定。

完整测试数据来源、当前支持范围与建议接入方式见 [测试数据接入说明](docs/test-data.md)。

## 从旧角色版本升级

先停止旧进程并备份数据库、录音、演示文件和公告图片目录，再启动新版本。数据库启动迁移会事务性升级 schema；旧版迁移会将原 `teacher` 账号转为管理员、原 `student` 账号转为普通用户，用户名、密码哈希、ID、会话和历史记录保持，旧 `role` 字段被移除。后续版本继续增加训练、公告、首页、直播课堂和热点趋势等结构；当前版本为 SQLite `user_version=34`。趋势迁移会清理旧趋势归档，每个日、周、月、年周期只保留最近一次生成结果。迁移依赖支持 `DROP COLUMN` 的 SQLite 3.35 及以上版本；回退旧代码需恢复匹配的数据库和文件备份。

API 不再返回或接受 `role`、`can_interview` 或 `can_exam`，客户端使用管理员身份及账号启停字段。比赛创建改为 `POST /api/admin/contests`，题目录入改为 `POST /api/admin/contests/{cid}/problems`；后台记录统一通过 `/api/admin/…` 访问。命令行使用 `--admin` 区分管理员和普通用户。

```sh
.venv/bin/python -m pytest -q
```

测试覆盖真实 PPTX 本地转换（需 LibreOffice 和中文字体）、中文字符实际字形、字体配置缺失报错、PDF 预览、上传及页数限制、无效替换保留旧文件、预览权限隔离、开场完成条件、历史面试兼容，以及默认管理员初始化与重复启动、短密码和任意字符用户名、用户名重置及重名校验、管理员全部系统访问、迁移、账号隔离、取消模块开关后的统一访问、邮箱验证码登录、管理员接口、账号停用、密码重置、面试状态、比赛时间、隐藏测试及 ASR 未配置时录音保留。判题路由使用假评测服务；真实 Docker 镜像执行需在 Docker daemon 可用的主机验证，真实 AI/ASR 调用另行配置验证。

前端资源更新后同步提升静态版本，并重启后端以加载新路由和逻辑；首页要求浏览器重新验证缓存，避免页面脚本与接口版本不一致。退出登录会撤销服务端会话。`judge.cleanup_timeout_seconds` 控制超时评测容器的清理等待上限，默认 5 秒；无法确认清理成功时返回评测服务异常。每次评测使用独立随机容器名，不操作其他容器。

V1.0 定位为单机试点，使用 SQLite、同步评测和本地录音及演示文件存储。部署应放在 HTTPS 反向代理之后，配置授权的 AI/ASR 服务并启用 Docker，备份数据库、录音、演示文件及 `app.upload_dir/announcements` 公告图片目录。暂不包含自助注册、批量导入、单点登录、多节点判题、审计报表或防作弊监控。

本地已有的默认管理员已一次性调整为 `root / root`，保留原账号 ID、权限和历史记录，原管理员会话失效；这不是每次启动执行的密码重置迁移。其他账号保持原样。

`[recording]` 统一配置 `bitrate`（64000）、`checkpoint_seconds`（15）、`live_chunk_seconds`（5）和 `finalize_grace_seconds`（120）。阿里云 ASR 使用 `[asr]` 配置；模型为 `qwen3-asr-flash`，上传前由服务端使用 ffmpeg 转为 16kHz 单声道 WAV。密钥只保存在被 Git 忽略的 `config.toml` 或后端环境变量中。数据库升级至版本 10：v5 新增全程录音表，v6 新增面试记录标题，v7 新增题库及学科选择字段；历史逐题录音不删除、不转换。

固定环节提示语首次合成后保存到 SQLite `speech_cache`，跨用户、跨场次和服务重启复用；专家问题音频按面试隔离保存，随面试或账号删除。缓存标识包含文本及 TTS 模型、音色、协议等配置，更换配置后重新合成；并发请求通过文件锁合并，失败不缓存，等待时限由 `tts.cache_lock_timeout_seconds` 配置。专家页仅自动播报，不展示播放器或问题重播按钮。点评保留原始 Markdown，读取时由服务端渲染标题、列表、表格等，前台与后台共用；禁用原始 HTML 与外部图片。

后台面试记录按用户 ID 归档，默认收起各用户的面试列表，支持用户名搜索、查看完成场数与最近面试时间；展开后查看该用户的记录，返回时保留已展开的归档。普通管理员的归档列表不包含管理员账号。

每日训练现分为面试篇、笔试-软件工程篇与笔试-人工智能篇，支持篇章内训练、重点回顾和私人投稿。软件工程篇包含116道整理校订题及历年题型改编，来源和修订记录见[软件工程题库校订](docs/written-software-curation.md)。AI篇包含202道整理校订问答题及57道文献翻译卡片，共259道；覆盖范围、补充项和修正记录见[人工智能题库校订](docs/written-ai-curation.md)与[文献翻译校订](docs/written-ai-literature-curation.md)。文献翻译支持先独立翻译、展开参考译文、关键词对照与来源说明，后台可独立筛选和维护。
