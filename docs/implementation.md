# V1.0 模块和部署说明

## 模块

- `app/config.py` 加载单一 TOML 配置，环境变量仅承载密钥。
- `app/db.py` 管理 SQLite 表：账号、会话、面试、逐题回答、比赛、题目和提交。
- `app/services/security.py` 负责密码哈希；`ai.py` 隔离生成模型和语音识别接口；`judge.py` 在受限 Docker 中运行 Python 3。
- `app/main.py` 提供 HTTP API、鉴权与流程状态检查；`app/static/` 是浏览器考生/教师界面。
- `judge/` 定义评测容器镜像；`scripts/` 提供教师创建账号命令。

上机流程采用 VJudge/洛谷式比赛列表、比赛起止时间、题目陈述、样例、隐藏测试、代码提交和判题记录。V1.0 不接入 VJudge/洛谷账户，也不代理其登录后的比赛内容。判题为同步单机模型，不适合多用户高并发。

## 面试流程

考生登录后开始场次；系统按配置生成前置固定题目。逐题回答录音保存，ASR 输出可由考生校对；完成前置题后，模型根据回答生成最后老师追问；考生回答后提交整场，模型生成点评。ASR 或模型不可用时，服务保留已保存录音/文本并返回错误，允许稍后重试。

## 安全与数据

题目管理、比赛管理仅教师可用；答案、录音和面试详情按考生身份隔离，教师可复核；学生只能在比赛时间内提交，不能读取隐藏测试数据。密码哈希和会话 token 不以明文存储。评测代码不得在宿主机执行。音频及源代码包含个人数据，机构需设置访问和备份策略。

## 配置

复制 `config.example.toml` 为 `config.toml`，字段注释见 README。也可用 `SCU_CONFIG=/path/to/file.toml` 指定路径。AI 和 ASR API key 只从对应的环境变量读取。
