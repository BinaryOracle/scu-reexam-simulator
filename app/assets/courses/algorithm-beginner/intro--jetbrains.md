# 配套 JetBrains 刷题插件

## 学习目标

建立 JetBrains IDE 的最小刷题环境，并理解模板、语言环境与提交之间的关系。

## 先有可运行的小项目

原文说明 JetBrains 系列 IDE 的刷题插件安装、平台选择和本地调试方式。不同 IDE 对语言的支持不同，选择与你实际提交语言匹配的产品和工具链；安装插件不会自动替代编译器、解释器或项目配置。

建议先建立一个最小程序，确认运行配置、工作目录和输入文件正确，然后再配置题目模板。核心代码模式可能需要测试包装来调用目标方法；完整程序模式直接使用标准输入输出。遇到“没有运行按钮”或“无法补全”时，先确认文件属于有效项目、语言 SDK 已选择，而不是立刻改动算法实现。

## 让调试过程可重复

把样例输入保存为本地文件，设置断点后观察递归参数、容器内容和边界变化。对于链表和树，画出节点关系再逐步执行，能更容易发现连接错误。检查性能时使用未开启单步调试的普通运行模式，避免把调试开销误认为算法超时。

插件的账户登录、题解入口和版本兼容可能调整，应查看原文的最新说明。对工具不熟悉时，完全可以先在浏览器题目页和一个普通本地项目之间切换；独立实现、验证和复盘的学习路径并不依赖某种特定插件。

## 动手练习

1. 建立一个能从标准输入读取整数并输出结果的项目。
2. 在递归函数入口和返回处设置断点，记录一次调用栈变化。
3. 用同一源码在普通运行和调试模式各运行一次，比较用途而不是只比较耗时。
