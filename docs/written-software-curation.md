# 软件工程笔试题库整理与校订

本题库用于复习，不是四川大学发布的官方题库、标准答案或对考试范围的承诺。历年考试题目来自上传材料中的考生回忆，部分题目缺少原卷、图表、公式或算法条件；改写和补充的条件已标为训练改编，不推测官方原题细节。

| 来源 | 页数 | 用途 |
|---|---:|---|
| （软件学硕）软件工程笔试个人复习笔记.pdf | 28 | 知识点、定义和复习方向；主要内容在1–22页，25页另有图片内英文选择题 |
| （软件学硕）软件工程历年笔试真题汇总.pdf | 9 | 2018、2019、2023–2025年考生回忆及题型 |

PDF的文件名、页码保存在每道题的`source.origins`中；出现重复主题时，两份材料均列为来源。每道答案由题库编辑重新组织，不照搬可能不准确的笔记。后台题目列表和学习卡片可查看来源及页码。题库JSON位于`app/assets/training/written-software.json`。

## 内容

共有116题：软件工程基础18题、需求分析17题、软件设计25题、软件测试23题、项目与配置管理17题，以及综合与历年题16题。主题涵盖生命周期与过程模型、可行性研究、DFD和数据字典、需求模型、模块化与结构设计、测试覆盖和黑盒技术、维护、规模估算、质量保证、配置管理和CMM。

综合题保留历年材料中的圈复杂度、测试设计、DFD/结构图、AI辅助软件工程、DCG、邮件分类和神经网络等方向。25页图片中的7道英文选择题被人工核对后纳入。2019年录取系统题保留已知的两项功能，不补写来源未提供的分数公式或业务规则。

## 校订说明

| 原材料问题 | 题库处理 |
|---|---|
| 将螺旋模型概括为“减少测试” | 删除该说法，解释螺旋模型的风险驱动循环 |
| 将原型模型说成基本线性 | 区分用于学习后抛弃的原型与演化式原型 |
| 把软件生命周期、软件过程和过程模型混用 | 分别定义三者并说明其关系 |
| 将系统测试与集成测试合并 | 分开描述测试级别，并说明迭代测试可跨阶段重复 |
| 将黑盒/确认与白盒/验证一一对应 | 说明验证和确认是目标概念，测试技术可以组合使用 |
| 把可用性测试与服务可用性混为一谈 | 分别解释 usability testing 与 availability |
| 圈复杂度公式遗漏图连通分量及二分支前提 | 给出`E-N+2P`的一般连通分量形式及`判定数+1`的适用条件 |
| 把预防性维护直接等同于再工程 | 分开说明维护目的、重构、逆向工程和再工程活动 |
| 配置管理任务和基线概念不完整 | 补充标识、版本、变更、状态报告、审计及变更控制 |
| 截图选择题仅有标红选项 | 第2题给定信息不足以唯一确定螺旋模型，改成过程选择辨析；其余题按题意说明答案理由 |
| DCG及邮件分类历年回忆缺少计算输入或算法 | 补充完整数据和约定，明确标为训练改编，不声称是原题答案 |
| 三角形题只保留了任务描述，没有原程序和分支 | 题目明确六个判定及统一出口，再计算圈复杂度和路径用例 |

资料覆盖并非完整教科书；参考答案是便于复习的要点，不替代教材论证。示例算法题的测试值、公式和假设均在题干或答案中明示。

## 验证

题库通过稳定`source_key`一次性导入。版本22迁移保留原`c_programming`集合ID、其中的题目、个人收藏、训练卡片、掌握状态及顺序进度；该集合显示名改为「综合与历年题」。管理员后续编辑的官方题目不因重新初始化而被题库JSON覆盖。
