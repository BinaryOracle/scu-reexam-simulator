# 写题工作区布局

根据用户提供的 LeetCode 参考图，将题面、代码、样例/提交记录组织为左侧整列与右侧上下两区，保留现有暖米白、朱红和深色编辑器。比赛导航和计时固定在工作区上方，不增加营销卡片或占位说明。

默认题面占横向 46%，代码占右侧高度 72%。两条分隔条支持指针捕获拖动、方向键微调、Shift 加速、Home/End 边界调整、双击恢复该方向默认比例；保持基本操作按钮可见。每区标题右侧提供放大/还原按钮，放大时保留原始比例，Esc 还原并回到对应按钮。顶部提供恢复全部布局的入口。

比例以用户 ID 隔离保存在浏览器，数据异常或存储不可用时仍可调整；放大状态不跨刷新保存。调整与放大通过 CSS 完成，保持代码、光标、滚动和评测结果 DOM。导航、切题时释放指针捕获、监听器和尺寸观察器。

1050px 及以下改用题面/代码页签，右侧仍支持上下调整。跨断点或切换页签退出放大，避免页签选中状态与可见内容不一致。

验证包含偏好恢复、非法偏好处理、独立分隔比例、放大还原、指针取消和导航清理测试，以及桌面、平板和手机布局实测。UI 验证使用隔离数据库，保留真实比赛与提交记录。
