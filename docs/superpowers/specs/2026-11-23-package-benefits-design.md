# 套餐自动权益

管理员登记购买是现有系统的购买确认入口。套餐配置包含模块开通、赠送积分、指定课程、飞书资源及其阅读/编辑/管理权限。配置修改仅影响后续登记，历史购买保留权益快照。模块仅追加开通，不关闭既有权限；积分与本地课程授权和购买记录在同一事务中提交。

课程授权独立于名单与积分购买记录，指定积分课程保存当前起止日期，私域课程无期限。课程仍需发布后才能学习，套餐不解锁草稿。下架套餐或移除金额登记不撤销已发权益，界面应明确说明。重新登记同一套餐不得再次领取积分；历史购买不追溯发放。

飞书授权使用官方协作者 API，管理员明确确认接收人的飞书邮箱或 Open ID，不假设网站邮箱就是飞书邮箱。分享密码不能代替应用或用户授权凭据。凭据只从服务端环境变量读取。支持自建应用获取并缓存 tenant_access_token，或外部维护的 user_access_token。文件夹需调用者管理权限和身份可见性。

外部授权写入独立任务记录后异步执行，不占用数据库写事务等待网络。保存状态、尝试次数、可操作的错误说明；后台支持失败/待发放任务重试。任务带租约，防止并发重试；超时表示结果待核实，不伪装成功。邀请者只查看金额和返利，不读取收件人和授权任务。

验证：事务回滚、重复登记、编辑不追溯、课程全链路权限、飞书协议/失败重试/身份隐私、备份与恢复、前端表单及样式检查。课程现存两条失败测试单独修复：未加入且无预览课时不返回进度；未加入公开课程不可直接取课件。
