# 课程学习系统设计

## 目标

把现有直播课堂升级为可组织直播、录播和文档资料的课程系统。管理员创建课程并维护内容；学员通过课程名单或公开课程自助加入后学习。现有 LiveKit 课堂能力、互动、录制和课程内主持人授权继续使用。

## 课程与访问

课程有草稿、已发布和已归档状态，以及公开加入或名单授权两种访问方式。草稿和归档课程不出现在公开课程目录；公开课程发布后允许普通用户加入；名单课程仅管理员分配的成员可访问。学员可退出自己加入的公开课程，退出后保留学习进度；名单分配的成员由管理员调整。取消公开发布不移除已有成员。管理员仍是唯一的课程配置者，不新增全局教师角色；课程主持人只在课程内获得现有的直播操作权限。

## 内容组织

课程按章节与课时排序。课时由有序内容项组成，支持 LiveKit 直播课、私有录播视频和私有文档。课时可包含一种或多种内容项，因此文档课、视频课和视频/文档交错都使用同一模型。既有独立资料仍可作为课时附件下载；新课时文档可在课时内容中排序呈现。

直播课时关联现有直播会话记录，评论、点赞、举手、主持人授权、Egress 录制和沉浸式课堂继续由直播模块负责。Egress 生成的可播放录播可添加为对应课时的视频内容，不复制媒体文件。管理员上传的录播视频与文档保存在应用私有目录，复用课程成员鉴权；视频接口支持 Range 请求和续播。单文件大小限制沿用统一配置，视频限制单独配置。

## 学员体验

课程目录按“我的课程”和“公开课程”浏览，支持搜索和课程状态提示。课程页显示简介、章节、课时和学习进度。课时页提供稳定的章节/课时导航及当前内容阅读区；直播课时进入现有课堂，录播视频可暂停和续播，文档可在线查看或下载。系统保存每位学员每个课时的视频播放位置与完成状态；打开文档可标记完成。课程完成度由已完成课时计算，不改变现有直播签到或录播状态。

## 管理体验

管理员可以创建草稿、编辑课程简介和访问方式、排序章节与课时、添加或移除内容项、上传/删除私有视频和文档、安排直播课并发布课程。公开课程的加入者自动获得课程访问资格；名单课程继续使用现有的管理员名单分配流程。直播进行中时保持现有约束，不能破坏主持人、成员、录制和文件操作。

## 数据兼容与权限

扩展现有课程管理，不删除或覆盖 `live_courses`、`live_members`、`live_lessons`、`live_materials` 和 `live_recordings` 的已存数据。新增章节、课程课时、内容项、公开加入关系和学习进度记录；既有课程和直播课次启动时幂等映射到默认章节及直播课时。直播 API 仍使用原有直播 ID，课程课时通过显式关联访问直播会话，避免改变已经使用的 LiveKit 房间名。

所有课程、课时、附件、视频、下载和播放请求由服务端校验课程访问权；未授权用户不能通过猜测 ID、文件名或旧播放 URL 访问资源。上传文件使用随机服务端文件名，校验扩展名、大小和空文件，并存放在非静态目录。播放继续使用短期票据并支持权限变更后拒绝请求。数据库升级递增 schema version，旧数据保留并可重复执行迁移。

## 主要模块

- 课程目录与课程详情：公开发现、我的课程、课程简介、章节与课时导航。
- 管理员课程编辑器：课程发布与访问设置、章节/课时排序、媒体及资料管理。
- 课程学习器：直播入口、录播播放、文档呈现、进度保存和完成状态。
- 课程 API 与数据层：课程访问策略、章节课时及内容项、成员与学习进度。
- 媒体文件服务：私有录播上传、受权 Range 播放和文件清理。
- 直播适配：课程课时关联既有直播 API 和 Egress 录播，不复制直播领域逻辑。

## 验证

测试覆盖旧数据库迁移及重复初始化、草稿/公开/名单课程权限、自助加入与退课规则、章节和课时排序、课时内容项、大小及类型校验、非成员下载/播放拒绝、Range 播放、播放进度和完成度更新、删除资源清理，以及直播课时仍可进入现有课堂和录播。前端检查课程目录、编辑流程、课时导航及桌面/窄屏布局。

## 本期不做

不实现付费购买、测验考试、证书、教师全局角色、第三方视频托管或面向 50 人之外的直播容量承诺。
