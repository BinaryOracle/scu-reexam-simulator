# ACM 模式代码模板

## 学习目标

掌握 C++11 完整程序、读到 EOF、多组输入及输出格式。

## 完整程序负责什么

完整程序需要包含头文件和 `main`，从标准输入读取题目规定的数据，最后向标准输出写出答案。输入可能有组数，也可能一直读到 EOF；二者不能混用。若首个整数是测试组数，应显式循环该次数，而不是把它当作业务数据。

下面是自行编写的“读到 EOF 后逐组求和”示例，只演示输入输出方式：

```cpp
#include <iostream>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    long long a, b;
    while (cin >> a >> b) {
        cout << a + b << '\n';
    }
    return 0;
}
```

输入 `2 7` 和 `-3 8` 两组数，应分别得到 `9` 和 `5`。如果题目按整行读取字符串，使用 `getline`；在格式化读取与整行读取之间切换时，要处理残留换行。不要用 `while (!cin.eof())` 判断是否读取成功，它可能导致末尾数据被错误处理。

关闭同步后保持一致的 C++ 输入输出方式。`endl` 会强制刷新缓冲，批量输出时通常使用换行符。Python 使用 `sys.stdin.buffer`，Java 可使用缓冲输入；语言不同，但都必须遵守题目的数据组织方式，不能凭模板猜测输入。

## 动手练习

1. 将示例改为先读组数 T，再读取 T 组数。
2. 写一个读取 n 和 n 个整数、输出总和的程序。
3. 用没有末尾换行的文件测试程序，确认 EOF 处理正常且没有多输出一行。
