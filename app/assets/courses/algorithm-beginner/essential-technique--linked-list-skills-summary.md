# 双指针技巧秒杀七道链表题目

## 学习目标

用哑节点、快慢指针和固定间距解决常见链表定位与合并问题。

## 不变量比指针名字更重要

合并有序链表时，让结果尾指针始终指向已经拼接好的最后节点；哑节点统一处理“第一个节点是谁”的问题。分隔链表时保留两条结果链的尾指针，移动原链节点前记住下一节点，结束后正确断开旧连接，避免产生环。

寻找倒数第 k 个节点可让前指针先走 k 步，随后两指针同步移动。当前指针到达末尾时，后指针就在所需位置，前提是先检查链表长度是否足够。快慢指针速度分别为 1 和 2，可用于找中点或判环：

```cpp
bool hasCycle(Node* head) {
    Node *slow = head, *fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

循环入口先检查快指针及其下一节点，才能安全前进两步。若发现相遇，将一个指针放回链头，两者每次走一步，可以定位环入口。相交链表判断比较的是节点身份，不是节点值；两个不同节点即使值相同，也不代表链表相交。

上述常见双指针算法通常只占常数额外空间。合并 k 条有序链表若使用优先队列，需要额外考虑队列大小和对数操作成本。

## 动手练习

1. 用长度为 0、1、2、5 的链表手算中点位置。
2. 画出带环链表中快慢指针前五次移动。
3. 实现删除倒数第 k 个节点，覆盖删除头节点和 k 超过长度的情况。
