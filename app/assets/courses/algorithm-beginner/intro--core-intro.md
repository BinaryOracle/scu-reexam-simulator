# 核心框架学习导读

## 学习目标

形成先认识框架、再练习变形、最后回顾框架的学习节奏。

## 核心框架是待检验的理解

本章把双指针、二叉树递归、动态规划、回溯和广度优先搜索放在一起，帮助建立知识之间的联系。第一次阅读时只需要理解每种方法主要解决什么问题，以及它维护什么状态，不必立即记住全部代码。

可以按“一个小例子—一句状态定义—一次手动执行—一个边界用例”的顺序学习。遇到滑动窗口就解释窗口中的元素代表什么；遇到递归就明确函数对输入承诺返回什么；遇到动态规划就写出状态和依赖。框架不能替代问题条件，尤其不能把某道题的更新时机直接搬到另一道题。

## 给每种方法建立检查单

| 方法 | 先回答的问题 |
| --- | --- |
| 双指针 | 为什么指针可以只朝一个方向移动？ |
| 递归 | 子问题与原问题的结果如何组合？ |
| 回溯 | 做出选择后，哪些状态必须撤销？ |
| BFS | 每走一条边的代价是否相同？ |
| 动态规划 | 哪些重复子问题可以合并？ |

看完本章后应立即动手实现。遇到某个框架还不理解，可以先跳到相关例题，再回来补充认识。用错题来修正对框架的理解，比为了“学完”而连续阅读更有效。

## 动手练习

1. 从表中选一个方法，用自己的语言解释其状态。
2. 不看讲义画出一个包含三个节点的递归调用过程。
3. 完成一道练习后回来修改最初的状态定义，记录新发现。
