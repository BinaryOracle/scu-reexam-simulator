# 首页编排与练习授权

## 首页编排

后台“首页编排”管理备考首页从“复试准备路线”开始的全部区块。支持新增备考路线或资源分组，修改标题、小标题和说明；路线步骤及资源卡片均支持新增、编辑、删除、展示开关和上下排序。资源卡片支持 0–5 星重要性、备注、站内页面与训练篇目、HTTP/HTTPS 外部链接。

编辑先进入本地草稿，可预览后点击“发布修改”一次发布。草稿在当前登录会话的页面切换间保留，刷新浏览器会丢失未发布修改并触发防丢失提示。“重新加载”放弃草稿并读取已发布版本。多个管理员同时编辑时，版本冲突返回 409，需重新加载后编辑，避免覆盖他人发布内容。

配置保存在 SQLite `app_settings.preparation_home_layout`，使用带类型及稳定 ID 的区块 JSON 文档，列表顺序即展示顺序。`app/assets/home-resources-v1.json` 仅用于首次导入，不再覆盖后台保存的配置。每次启动幂等保留已发布内容；数据库备份包含首页配置。前台读取 `/api/home/layout`，仅返回已展示的区块和内容；后台 GET/PUT `/api/admin/home-layout` 读取及事务发布完整配置。旧 `/api/home/resources` 投影已展示的资源卡片，供旧客户端读取。

## 统一练习权限

用户字段 `can_practice` 同时控制每日训练和算法题带刷。所有启用账号均可浏览两个模块首页、篇目及阶段概览，也可管理个人投稿。每日训练开始、继续作答、签到、公共题库与答案图片，以及算法每日抽题、公共题单、题目详情、提交与签到均由服务端校验。算法首页对未授权用户隐藏抽题、签到及完整练习列表；每日训练点击开始时明确提示联系管理员。私人题的编辑不依赖练习权限，执行编程练习仍需授权。

管理员在用户列表切换“练习权限”，创建普通用户时也可勾选；管理员始终具有有效练习权限。新注册及后台创建的普通用户默认未开通。迁移到 v28 时已有账号保持原来的练习能力，之后的重启不再次授予权限。授权与撤销在后续接口请求生效，包括已开始的训练；旧面试次数、投稿奖励与比赛参赛名单独立管理。

## 比赛参赛名单

所有登录用户可查看全部比赛列表。新建比赛默认采用指定名单，后台创建或编辑比赛时搜索用户名、邮箱并勾选参赛用户，支持选择当前筛选结果和清空。空名单表示仅管理员可进入；停用用户即使在名单内也不能登录访问。管理员保留比赛管理能力，无需加入名单。

比赛详情、赛后回顾、排行榜、题目、提交及个人提交详情均验证本场名单；用户不能通过猜测 ID 或旧链接绕过。名单撤销后，其历史提交仍留在数据库供后台复核，但个人提交列表不再显示该比赛的记录。删除比赛或用户会级联清除名单关联，不影响其他比赛。开始前的题面与比赛时间限制继续生效。

v28 迁移时旧比赛保持原来全部用户可访问的状态；后台编辑会预选当时的全部普通用户，保存后改为固定名单，后注册用户需另行添加。名单通过 GET `/api/admin/contests/{id}/participants` 读取；创建和编辑比赛传递 `participant_ids`。编辑接口省略该字段时保留名单，新建接口省略时使用空名单。参赛用户 ID 只接受现存普通用户，名单、比赛和题目在一个事务中更新。
