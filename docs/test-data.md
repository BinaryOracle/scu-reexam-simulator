# 上机题目的测试数据接入

题面中的样例不等于完整评测测试集。看到题面、提交通过或拿到 Accepted，都不代表拥有原站隐藏测试文件。测试集指该题用于判题的一组有限数据，也不能证明覆盖了所有可能输入。

## 来源选择

| 来源 | 能否取得完整数据 | 接入方式 |
| --- | --- | --- |
| VJudge 聚合题 | 通常不提供原 OJ 隐藏测试集下载 | 回到题目的原站，检查是否有官方公开数据包；或者使用允许的远程评测方式 |
| 洛谷题目 | 按题目、公开设置及账号权限决定，不能假定所有题均可下载 | 题页有官方测试数据入口且当前账号有权限时下载；否则向出题方取得授权数据 |
| ICPC 等比赛官方资料 | 部分比赛发布完整题包，部分仅有题面、题解或样例 | 检查官方归档/仓库的具体文件、版本和使用许可 |
| 出题方授权、自己制作的题包 | 由提供方交付范围决定 | 获取输入输出、标准解、数据生成器、校验器及必要的 checker |

Kattis 的 [problemtools](https://github.com/Kattis/problemtools) 提供题包校验工具和示例；[题包格式规范](https://www.kattis.com/problem-package-format/) 可作为数据组织参考。这些工具和格式规范不代表能下载 Kattis 平台所有题目的隐藏数据。Polygon 的题包也需由有权限的出题者导出，公开题面不等于公开题包。

对于四川大学复试模拟，建议优先使用允许再使用的官方公开题包，或由机构自行命题并生成数据，保证本地限时考试不依赖外部 OJ 的可用性。没有原始数据时，可以自建边界、随机和性能测试，并用标准解对拍，但应标记为自建测试，不能称为原站完整测试集。

## 当前系统实际支持

V1.0 使用本地 Docker 评测，尚未接入 VJudge/洛谷远程评测、ZIP 题包导入、Polygon/Kattis 格式转换或 special judge。后台目前通过「录入题目」填写输入输出 JSON：

```json
[
  {"input": "1 2\n", "output": "3\n"},
  {"input": "0 0\n", "output": "0\n"}
]
```

每项对应一个用例，后端限制每题 1–50 个用例。输入、输出为字符串；与样例字段分开保存。普通用户接口不返回隐藏数据。当前判定使用去除末尾空白后的字符串比较，不支持浮点误差判定、多解 checker、交互题、分组计分；Python 3 单语言及资源限制也需与选题匹配。因此，取得完整数据包后仍需确认评测规则兼容，不能仅复制文件就认为与原 OJ 判定等价。

## 建议的下一步

优先增加管理员题包导入：上传配对的 `.in/.out` 或 `.in/.ans` 文件、预览对应关系、核验遗漏/重复文件、设置时间和内存限制，并保存来源与使用许可。导入前限制压缩包解压大小、路径及用例规模；仅存储数据，不在导入时运行题包内任意程序。若之后支持 checker 或数据生成器，应放在独立受限环境执行。

远程评测应作为另一种题目来源，记录原站题号并通过原站允许的接口/方式提交和查询状态。它能使用原站数据判题，但不把隐藏测试集复制到本系统；账号、限流、验证码、平台协议及外部故障会影响考试体验。当前版本没有实现该功能。
