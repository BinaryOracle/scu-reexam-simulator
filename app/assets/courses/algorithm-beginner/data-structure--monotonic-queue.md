# 单调队列结构解决滑动窗口问题

## 学习目标

用双端队列维护固定窗口最大值，同时处理候选淘汰和过期。

## 两种弹出处理两种原因

队首保存最大值候选；新元素加入时，从队尾移除不比它大的旧候选，因为这些旧值更小且更早过期。窗口向前移动后，再从队首移除已经离开窗口的索引。这两种移除不能混为一谈。

```cpp
vector<int> windowMax(const vector<int>& a, int k) {
    if (k <= 0 || k > (int)a.size()) return {};
    deque<int> q;
    vector<int> result;
    for (int i = 0; i < (int)a.size(); ++i) {
        while (!q.empty() && q.front() <= i - k) q.pop_front();
        while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
        q.push_back(i);
        if (i >= k - 1) result.push_back(a[q.front()]);
    }
    return result;
}
```

保存索引可以直接判断过期，遇到重复值也不会把仍有效的另一个相同值误删。示例选择相等时保留更新的索引，它值不小、过期更晚，所以足以代表最大值候选。

每个元素最多入队一次、出队一次，时间 O(n)，队列空间 O(k)。与优先队列不同，双端队列利用窗口只向前推进和最大值单调淘汰的性质；如果需要随意删除中间元素或任意范围查询，不能直接沿用。

先验证窗口不足 k 个元素时不输出，再验证 k=1 和 k=n；输出数量应为 n-k+1。

## 动手练习

1. 跟踪 [1,3,-1,-3,5]、k=3 的双端队列。
2. 用重复最大值测试过期删除是否正确。
3. 修改比较方向实现窗口最小值，并说明算法性质为何仍成立。
