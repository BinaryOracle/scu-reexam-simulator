# 学习数据结构和算法的框架思维

## 学习目标

从存储、遍历和搜索空间三个角度分析算法问题。

## 结构与操作一起考虑

数组提供连续索引访问，链表通过引用连接节点；许多容器是在这些基本方式上组合索引、指针或辅助信息。选择数据结构时同时考虑查找、插入、删除和遍历的成本，而不是只记住结构名称。

对一个问题先给出能够覆盖所有候选解的暴力方法，再找减少重复计算或排除无效候选的依据。二分利用单调性舍弃半个区间，动态规划合并相同子问题，回溯在选择树上搜索，剪枝必须解释为什么不会漏掉合法答案。

## 两种递归组织方式

遍历方式让每个节点对外部状态作贡献；分解方式规定子函数返回值，再组合为当前答案。例如求树节点数可以写成：

```cpp
int countNodes(Node* node) {
    if (!node) return 0;
    return 1 + countNodes(node->left) + countNodes(node->right);
}
```

函数含义是“返回以 node 为根的节点数”。空树返回 0，子树各自完成同样任务，再加上根节点。计算时间取决于实际访问的节点数，额外空间来自递归调用栈；链状树的栈深可达节点数，不能一律写成对数空间。

从暴力到优化的每一步都要保留可解释的不变量或递推含义。能写清楚这些约束，才知道一个模板什么时候可用、什么时候必须调整。

## 动手练习

1. 分别用遍历计数和返回值组合计算树高，比较外部状态。
2. 为一个数组求两数之和问题写暴力思路，再说明哈希表减少了哪类工作。
3. 对空树和单链状树手算示例的返回值与递归深度。
