# V1.0 模块和部署说明

## 模块

- `app/config.py` 加载单一 TOML 配置，模型密钥按对应服务的环境变量或配置读取。
- `app/db.py` 管理 SQLite 连接事务和版本迁移，以及账号、会话、面试、演示文件、逐题回答、面试题库、比赛、题目和提交表。
- `app/services/auth.py` 负责会话、账号启停和管理员身份校验；`security.py` 负责密码哈希；`interviews.py` 提供统一面试详情查询。
- `app/services/presentations.py` 负责文件检查、Office 转换和 PNG 预览；`app/routes/presentations.py` 负责私有预览授权、上传与开场完成。
- `app/services/ai.py` 隔离生成模型和语音识别接口；`judge.py` 在受限 Docker 中运行旧版本地比赛的 Python 3 提交，洛谷桥接由浏览器插件提交 C++11、C、Python 3、Java 和 Go 代码。
- `app/services/luogu_catalog.py` 导入洛谷公开题面和全部样例；`problem_content.py` 安全渲染 Markdown，公式由随站点分发的 KaTeX 静态资源排版。
- `app/routes/admin.py` 提供管理员账号、面试题库和记录复核 API；`app/main.py` 提供登录、个人面试抽题、上机与考务写入 API。
- `app_settings.luogu_app_origin` 保存管理员统一设置的插件网站来源，默认为 `http://127.0.0.1:8000`；插件 ZIP 下载时生成对应扩展来源权限和配置。
- `app/services/credits.py` 和 `app/routes/credits.py` 管理次数、卡密发行、兑换和个人主页；`password_vault.py` 管理供后台查看的密码加密副本。
- `app/static/` 提供共享主题的前台和后台：`app.js` 管理登录与导航，`api.js` 管理请求及权限错误，`ui.js` 提供共享组件，`admin.js`、`interview.js` 和 `contest.js` 分别管理账号、面试和上机界面；`presentation.js` 管理文件选择、翻页与全屏预览，录音仍由面试组件管理。
- `app/assets/question-bank/` 保存各学科 JSON 和英文题库，以及供首次导入使用的统一目录；运行期间由管理员 API 管理 SQLite 题库。
- `judge/` 定义评测容器镜像；`scripts/create_user.py` 提供首次管理员和普通账号创建命令。

判题进程超时时，显式强制移除本次随机命名的容器；仅终止 Docker 客户端不能保证容器退出。清理失败返回 `Judge Error`，不把仍可能运行的评测报告为正常超时；清理等待上限通过 `judge.cleanup_timeout_seconds` 配置。

前台入口为 `/`，后台入口为 `/admin`。前台不展示后台入口，两者共享页面和组件，通过路径确定上下文；页面切换写入 URL hash，浏览器前进、后退与刷新会恢复主页面，比赛子页面与当前题号一并编码在 hash 中。洛谷桥接账号标记按用户保存在浏览器本地；恢复洛谷答题工作区后自动重新检测插件与登录状态，不保存洛谷凭证。服务端 `/api/admin/…` 强制验证管理员权限，页面隐藏不是授权依据。新比赛仅使用洛谷浏览器桥接；管理员搜索洛谷题号或关键词，选择至少一道题后一次性创建比赛与题目。比赛列表、比赛信息和题目工作区分开显示，开赛前只返回赛程和题目标题；比赛创建后可编辑名称、起止时间与题目。题目使用稳定的本地 ID 关联提交；不能移除已有提交的题目，更新其题面不会删除提交。管理员可重新导入洛谷公开题面、资源限制和样例。原始 Markdown 存入 SQLite，接口提供关闭原始 HTML 的渲染结果；本地 KaTeX 负责公式展示。删除比赛在一个数据库事务中清理关联提交、题目和比赛。洛谷插件的动态内容脚本仅获准访问用户配置的本站来源；用户点击提交后由扩展服务工作线程选择其已登录的洛谷标签页，使用浏览器现有会话提交并读取远端记录状态，不自动打开或切换原题页。状态推送不重复相同判题结果；页面暂不可达时暂存同步数据，并在下次检测连接时重试。逐测试点结果转换为判定标签后回传，不携带隐藏测试输入。Cookie 不离开浏览器。扩展 1.1.4 使用洛谷当前 `lang` 字段和语言编号、读取顶层 `rid`，支持站内人工图形验证码输入与错误重试；交互验证由用户在洛谷页面完成，结果未知的网络失败不自动重投。协议核对和复测见 [洛谷提交桥接](luogu-bridge.md)。插件压缩包由 `/api/luogu-extension` 从固定文件清单实时生成。洛谷状态由用户浏览器读取并回传，服务端未独立认证远端结果，因此不能作为正式排名或成绩凭证；应通过洛谷记录链接复核。洛谷页面接口并非本系统可承诺稳定的公共 API，页面改版、安全校验或平台规则可能使桥接停止工作；不得将其结果误报为本站 Docker 评测。

## 面试流程

新面试准备页通过 `GET /api/interview-setup` 读取模板及上传限制，只在浏览器保留所选文件，不上传文件或创建记录。底部「开始模拟面试」按钮先申请麦克风权限，再通过 `POST /api/interviews/start` 上传文件；转换成功后在事务中创建场次、题目及 PPT 关联并开始计时。转换失败不留空记录，返回记录首页会释放所选文件。既有场次仍可使用按 ID 开始的接口。

新场次使用 `workflow_version=5`，通过 `start` 保存开始及截止时间；浏览器先检查麦克风权限，成功后自动开始主录音。`interview-audio.js` 独立管理麦克风检测、全程录音、累计备份、最终上传和实时转写；`recordings.py` 管理录音片段私有存储、ASR 和最终上传窗口。主 MediaRecorder 跨环节复用，ASR 使用独立短片段或浏览器识别；前端先排空旧环节的识别结果，再保存文字并切换，防止结果串入下一环节。开始后不得替换 PPT，预览授权和转换规则沿用原实现。

stage 2 为专业课卡片：首次抽题选择一个学科，未提交回答前可从另一学科换题一次；stage 3 随机抽取英文段落翻译题，stage 4 随机抽取英文口语题。题面、学科和选择次数写入 `answers`，刷新和复盘保持不变。stage 5 仍为根据已保存回答生成的 AI 专家追问。管理员维护题库需要后台权限；停用或删除题目不会改变已抽取并保存的面试答案。

`POST /api/interviews/{id}/recordings` 只在面试进行中创建片段；`PUT …/recordings/{rid}` 保存累计备份，final=true 上传最终音频。结束和截止后的窗口仅允许最终音频补传，按配置限制时间；最终内容不可覆盖，相同摘要重试幂等。`POST …/answers/{stage}/live-transcribe` 识别独立短片段并在返回前再次检查截止和环节；临时文件始终清除。`POST …/recordings/transcribe` 识别已保存的全程声音，写入前核验摘要；音频变化会清除旧转写，避免点评使用旧文本。详情只返回录音元数据及转写，不暴露存储路径。

复盘播放器隐藏浏览器原生控件，使用原生范围输入提供键盘与触屏可访问的定位；拖动期间预览时间，提交后设置音频播放位置。全程录音分片仍单独加载，同一面试详情切换环节时保留播放器实例与时间轴位置。展开完整回答时使用独立复盘样式扩大文本区域，不改变进行中作答区尺寸。

自我介绍完成条件为 PPT 和已保存声音，新流程不强制手动转写；旧流程继续检查逐题录音及文字。结束接口独立于 AI，保存回答后停止主录音、锁定面试并补传最终声音；前端默认回到第一环节。只有已存在专家题的场次开放点评，模型输入包含逐题答案和全程转写；模型失败保持已结束状态，可重试。详情见 [十分钟面试与录音](interview-timing.md)。

Office 转换子进程按 `presentation.fontconfig_file` 加载字体目录及中文替代规则，独立用户目录避免并发转换共享 LibreOffice 配置；不修改主进程环境或系统字体。中文回归用例检查真实转换 PDF 中的中文字形编号，避免仅凭可提取文字误判显示正常。修复历史预览需从原始 PPT 生成新目录后，仅切换演示表的目录和页数，保留旧目录；不调用上传接口，不重置回答、录音或开场完成状态。字体安装及配置见根 README「PPT 转换与存储」。

计时由 `app/services/interview_clock.py` 根据配置和场次数据库时间计算。接口对答案、音频、ASR 与 AI 追问分别在外部耗时步骤后重新验证截止时间，防止迟到结果写入；超时点评只取库中已保存的答案。浏览器显示时间以接口返回的剩余秒数为基准并用单调时钟递减，在同一场次的环节切换间复用基准；它不决定服务端是否接受写入。

自我介绍完成按钮先保存当前输入，再调用完成接口，两个请求顺序执行；任何一步失败都不会切换环节。保存期间锁定输入并阻止导航，完成失败时已保存的文字仍可编辑重试。自我介绍不显示单独保存按钮，其余问答环节保留原有保存操作。

## 权限与数据

`PATCH /api/interviews/{id}` 保存非空标题（最多 100 字），列表及详情返回标题。所有状态的本人面试记录均可改名或删除，包括进行中的面试。`DELETE /api/interviews/{id}` 校验记录所有权，事务删除回答、录音、演示引用与场次，提交后清理对应私有文件。删除不返还已扣次数，前台删除按钮需二次确认；后台查看他人记录保持只读。

所有启用账号均可访问面试与上机系统，模拟面试通过次数限制使用；旧 can_interview/can_exam 字段仅保留存储兼容，不参与授权、不接受写入且不在 API 返回。普通管理员只可管理普通用户及其记录；超级管理员还可管理普通管理员和读取管理员记录。root 的 is_superadmin 与账号 ID 绑定，改名不转移身份。普通用户的回答、录音和提交按账号隔离；上机比赛开始前不开放题面，隐藏测试不返回浏览器。

每次认证重新读取身份和启停状态，停用和密码重置删除该账号全部会话。当前管理员不能停用/降权自己，系统至少保留一个启用管理员。改名仅校验非空和唯一性，保留账号 ID、邮箱、会话、密码和记录；密码重置要求填写，不设复杂度规则。

邮箱验证码服务由 `services/email_auth.py` 和 `routes/email_auth.py` 管理，发送邮件使用配置的 QQ/腾讯企业 SMTP。验证码不以明文存入数据库或日志，验证成功后单次消费；首次登录自动注册普通用户，以完整邮箱作为默认用户名、随机生成初始密码，从数据库的当前默认次数设置发放初始余额。管理员创建账号可预设唯一邮箱。个人主页通过独立账号路由修改用户名、验证身份后修改密码或注销；变更邮箱必须验证新地址，验证码用途和账号绑定，不可混用。配置方法见 [邮箱登录](email-login.md)。

公告 Markdown 正文及附件索引保存在 SQLite；公告图片写入 `app.upload_dir/announcements`，默认公告封面随应用静态文件发布。服务端渲染时禁用原始 HTML，只允许正文引用已经上传的本站图片；管理员预览草稿时使用管理员附件接口，普通用户仅能读取已上架公告引用的图片。备份部署数据时需包含公告附件目录；附件文件不能只靠 SQLite 数据库恢复。

数据库使用 `PRAGMA user_version` 记录版本，旧角色迁移会保留账号 ID、密码哈希和记录关联，移除 `role`。v2 迁移为已有管理员补齐两个模块权限；v3 新增 `presentations` 表和面试流程字段；v4 新增面试开始、截止和结束时间；v5 新增 interview_recordings 表，新建面试启用 `workflow_version=5`，已有记录保持原流程；v6 增加面试标题；v7 新增 `question_bank` 及答案题目元数据，空题库首次从 JSON 导入；v8 新增密码加密副本；v9 新增次数余额、面试扣次标记、系统设置、卡密与次数账本；v10 新增持久超级管理员、动态套餐表和卡密兑换用户名快照；v11 保存专业课题目选择历史；v12 新增持久语音缓存表；v13 新增邮箱身份及验证码限流存储；v14 新增变更邮箱及安全操作的验证码存储；v15 为上机题目保存完整的公开样例列表；v44 为课程配置和课程购买记录保存访问起止日期，并为旧课程配置生成兼容日期范围。迁移可重复执行且不会重置账号余额或重复发放体验次数；高于程序支持版本的数据库拒绝加载。升级前配套备份数据库、密码查看密钥及私有文件，迁移映射和 API 变化见根 README。

登录使用 scrypt 哈希，会话 token 校验有效期。另存 Fernet 认证加密的密码副本，仅通过管理员专用接口显式查看，列表不返回原文或密文。旧账号成功登录或重置密码后才可建立副本。密钥位置、备份要求及次数规则见 [次数与卡密](credits-and-vouchers.md)。评测代码不在宿主机执行。音频、文本及源代码包含个人数据，应通过 HTTPS 提供服务并设置备份策略。

## 配置

复制 `config.example.toml` 为 `config.toml`，也可使用 `SCU_CONFIG=/path/to/file.toml` 指定配置。AI 密钥从对应环境变量读取，ASR 优先使用 `asr.api_key`，未配置时读取对应环境变量。运行时限制、数据目录、面试问题、模型地址和初始卡密套餐等集中配置；运行期间套餐由数据库维护；用户身份、启停及余额属于账号数据，在管理后台维护。`credits.default_credits` 用于首次初始化，默认 1，后台修改后以数据库设置为准；管理员统一为 999999，开始面试不扣减。

专家语音使用百炼 `qwen-audio-3.1-tts-plus` 的 HTTP `SpeechSynthesizer` 协议。`[tts].base_url` 默认使用已真实验证的北京公共地址 `https://dashscope.aliyuncs.com/api/v1`，也支持配置同地域 Workspace 专属地址；请求使用模型音色 `longanhuan_v3.1`、WAV 和 24 kHz。服务端从配置的 API Key 环境变量读取密钥，响应音频仅允许从 `download_hosts` 中列出的 HTTPS 域名下载。官方地址与请求字段见[语音合成 HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)和[音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。

空数据库初始化时创建 `root / root` 并赋予全部权限及唯一超级管理员身份。判断条件为用户表无任何账号，已有数据库不会补建或重置默认管理员。用户名、密码均要求非空；除用户名唯一性外不设字符格式、长度上限或复杂度规则，前端、HTTP API 和命令行保持一致，用户名不裁剪空格。默认管理员密码也以 scrypt 哈希保存。

## 公共参考模板

`presentation_template.py` 提供配置化模板说明、原始文件下载及预先生成的预览。共享模板不会写入用户的 `presentations` 表，不改变开场完成条件。准备页提供年度说明、下载链接与官网链接；正式自我介绍与专家问答页仅放映用户上传的文件，不再展示模板说明。后台仅展示用户上传的文件。原文件完整保留，附件中的填写说明仅作为模板内容展示，不作为系统指令执行。

后台 `DELETE /api/admin/users/{uid}` 在事务中删除用户及关联私有记录，提交后清理文件；卡密保留已兑换时间和用户名快照。不能删除超级管理员和当前账号。前台所有主动确认与输入操作使用 `ui.js` 的原生站内 `<dialog>` 组件，保留焦点管理、取消与 Escape 行为。个人主页始终提供兑换入口和服务器会话退出，移除固定套餐卡片；管理员内部额度不在前台 API 或界面中输出。

数据库 v11 为 answers 增加 question_history JSON 列，保存专业课首次抽题与换题后的 question/subject 有序列表。迁移仅记录旧数据尚存的当前题，复盘明确标注未保存的旧原题。面试列表返回 has_feedback 标识，避免传输完整点评。

`speech.py` 在 SQLite `speech_cache` 保存合成音频和 MIME；通用提示不关联面试，专家音频以外键关联场次并级联删除。模型、音色、接口、协议、格式、采样率、语言和原文共同决定缓存标识；文件锁跨进程合并缓存未命中请求，网络合成期间不占用数据库事务。`feedback.py` 使用 markdown-it-py 渲染保存的 Markdown，禁用原始 HTML 和图片语法，默认链接校验阻止脚本协议。详情新增 `feedback_html`，列表仍仅包含 `has_feedback`。

账号 ID 通过 `app_settings.user_id_highwater` 持久递增分配，删除账号不回退；默认管理员、后台创建、邮箱注册和命令行创建共用分配器。PPT 转换完成后的提交事务会重新验证原登录 token、账号启停和到期时间，转换期间注销、登出或改密码会阻止旧请求创建面试或扣次，并清理临时预览。用户主动注销成功后清理当前浏览器中该账号的上机草稿及面试恢复标记。

套餐权益配置与飞书协作者授权的产品流程、失败处理和部署变量见 `credits-and-vouchers.md`。套餐权益表与购买快照通过 SQLite 初始化迁移创建，并纳入账号/积分/课程/直播关联备份。
