# 比赛重点信息与直接选题

保留暖米白、棕色和朱红配色，将比赛详情中的倒计时、时间进度与排名作为主要视觉信息。剩余时间采用等宽数字，时间条表示比赛已用比例，开始与结束时间位于两端；未开赛显示距离开赛，结束后进度停在 100%，最后五分钟使用红色提示。写题页保留同一时间模型的紧凑版本。

题目导航按题号和题名的自然宽度排列，选中项使用朱红背景。详情页每行使用可聚焦按钮，包含题号、题名、分值和尝试/通过次数；点击直接进入对应题目，地址保留题目 ID。普通用户开赛后可以进入题目，结束后允许查看，提交仍受比赛时间限制。进入工作区的异步请求在离开页面或更新目标后失效。

排行榜采用深酒红标题区、金色奖杯及前三名徽章，突出得分与当前用户，明确区分通过、未通过和尚未尝试。表格保留语义表头、表题与横向滚动，失败时提供刷新入口。手机布局压缩辅助信息，题目按钮和倒计时保持可用；进度动画尊重减少动态效果的系统设置。

验证覆盖开赛前、进行中、最后五分钟、结束后的时间计算，以及题目访问规则。使用隔离数据进行桌面和手机交互验收，检查指定题目导航、排名刷新、结束后禁用提交和原有工作区分栏。
