LUOGU BRIDGE

连接洛谷提交插件

  1. 先下载插件 ZIP 并解压到一个固定目录，之后不要移动或删除该目录。
  2. 在 Chrome 或 Edge 打开扩展程序管理页，开启开发者模式，选择“加载已解压的扩展程序”，选中解压出的 browser-extension 文件夹。
  3. 无需填写知序网站来源；插件包已由管理员统一配置本站地址，并会自动连接知序页面。
  4. 刷新知序页面；在同一浏览器新开洛谷并登录，保持洛谷标签页打开。
  5. 打开比赛题目工作区，点击“检测洛谷登录状态”。显示已连接后再开始答题。

代码仅由你的浏览器发往洛谷；本站不读取或保存洛谷密码、Cookie。若洛谷要求验证码，插件会打开对应题目页；请按洛谷页面提示完成验证，再回到知序重试。
