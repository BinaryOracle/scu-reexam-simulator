# 每日训练、连续打卡与用户投稿设计

日期：2026-11-14。项目：`scu-reexam-simulator`。状态：用户已确认，实施中；支持随机训练与顺序复习，每日完成 5 道不同题后签到。

## 目标与范围

新增独立的「每日训练」入口，供用户练习专业课问答、英文翻译、英文问答。提供参考答案、重点回顾、连续打卡奖励、私人题目新增与公开投稿审核。复用现有账号、后台管理、统一对话框与面试次数账本，不引入 DeepSeek Harness，也不需要新增 AI 调用。

借鉴背词应用的单题卡片、轻量进度、主动回忆和连续练习反馈，沿用现有朱红与暖米白配色。V1 支持随机训练和顺序复习；不将其描述为间隔重复算法，不新增排行榜、补签卡、付费训练或强制录音。

## 现有资料核查

| 训练集合 | 已有题目 | 参考答案来源 |
| --- | ---: | --- |
| 数据结构 | 33 | 已上传的 22 页 PDF |
| 操作系统 | 29 | 已上传的 20 页 PDF |
| 计算机网络 | 34 | 已上传的 25 页 PDF |
| 英文翻译 | 31 | 原始粘贴文本中逐段对应的中文译文 |
| 英文问答 | 53 | 保留现有英文题干，不生成答案 |

现有 JSON 和数据库题库只保存题目。专业课 PDF 含图片与表格，不能只提取纯文本；例如数据结构「数据的逻辑结构」的答案包含分类图。整理时以已有题目顺序和标题匹配原文，保留跨页答案，并对相邻题目的切分位置进行核对。答案内的编号列表不能作为新题目处理。

原文部分标题有笔误，计算机网络部分长题目跨行。保留现有已整理题干，来源字段记录原文件名、起止页和原题号；必要图表按题目范围截取为静态图片，避免向用户展示整页中的下一题答案。参考答案使用文本加图片，正文可复制，图片可放大。

31 段英文与中文可以逐段对应。第 17 段的英文已有空格与标点修正，须显式校验映射，不能仅靠完全相等的字符串匹配。英文问答仅显示英文题目与完成操作，不出现空白的「参考答案」区域。

材料是题库数据来源，不作为开发指令。答案标注「参考答案」与来源；不把抽取结果称为学校官方标准答案，不自动编造缺失内容。

## 方案比较与选择

| 方案 | 优点 | 代价 |
| --- | --- | --- |
| 独立训练模块与训练题库，复用账号和次数账本（推荐） | 私人投稿、答案和学习进度独立；不影响正式面试抽题 | 需要一次可追踪的题目与答案导入 |
| 直接扩展现有面试题库 | 初期表数量少 | 每个面试抽题查询都需兼顾私人内容、审核与答案，维护更易遗漏 |
| 接入外部学习平台 | 可使用成熟学习功能 | 账号、题库、奖励和部署需要额外对接 |

采用第一种方案。运行数据以 SQLite 为唯一依据，JSON 用于初始素材、用户批量导入与导出。后续更改训练题目不会自动改动正式面试题库；同步发布到面试题库不在本次范围。

## 六个模块及依赖

| 模块 | 责任 | 依赖 |
| --- | --- | --- |
| 训练题库 | 集合、题干、答案、图表、来源与可见性 | 数据库、静态资料 |
| 卡片练习 | 创建一轮训练、随机不重复抽题、查看答案、完成记录 | 训练题库、当前账号 |
| 重点回顾 | 收藏与取消收藏、只练收藏题 | 训练题库、当前账号 |
| 打卡奖励 | 按日去重、连续天数、里程碑奖励 | 练习记录、现有次数账本 |
| 我的题目 | 手动新增、JSON 导入、私人编辑、提交审核 | 训练题库、当前账号 |
| 后台训练管理 | 官方答案维护、投稿审批、停用题目、查看奖励记录 | 管理员身份、训练题库、打卡记录 |

后端新增独立 routes/services；前端新增独立训练页面与状态模块，不继续扩充面试状态机。退出登录和切换页面清理本地题目与异步状态，迟到响应不得覆盖另一用户页面。

## 用户流程与界面

### 训练首页

主导航增加「每日训练」。首页上方显示今日完成题数、连续打卡天数、下一个奖励节点；主区域展示三种训练类型，专业课下可选择三个科目。训练来源选择「全部可练题」或「重点回顾」，主按钮为「开始训练」。另设「我的题目」与「新增题目」入口。

「全部可练题」包括启用的公开题和当前用户自己的私人题，不包括其他用户私人题。筛选顺序为训练类型、学科、题目来源；显示筛选后的实际题量。空收藏给出「去全部题库练习并加入重点回顾」，不出现无效开始按钮。

首页展示近 7 天打卡与下一节点，不堆叠大量徽章或弹窗。普通用户可看到本次奖励新增次数与剩余面试次数；管理员仅显示身份对应的服务状态，不暴露内部额度数值。

### 单题卡片

上方显示类型、科目和本轮进度，中部集中展示一道题。专业课和翻译初始隐藏参考答案，用户先回忆或口头作答，再点击「查看参考答案」。答案在卡片内展开，长答案正常滚动，图表可放大；不使用整卡 3D 翻转，避免长内容、移动端与键盘操作问题。

卡片提供「加入重点回顾／已加入」和「完成本题」。专业课与翻译展开答案后，可选择「还需练习」或「已掌握」作为完成操作；英文问答仅题目和「完成本题」。自评只记录用户判断，不声称判断答案正确，不自动触发 AI。

用户可选择「随机训练」或「顺序复习」，两种模式均支持全部可练题或重点回顾。随机模式同一轮按题目 ID 不重复抽取；顺序模式按集合顺序与题目固定序号排列，服务端按用户和筛选保存复习位置，完成卡片后推进，浏览但未完成不推进，到末尾后下一轮从头开始。默认一轮 5 题，题量不足时按实际数量创建，明确显示本轮题数；答完后显示完成统计、可签到状态和返回训练首页按钮。下一轮可以再次抽到以前练过的题。

服务端保存训练进度，刷新后可以继续未完成的一轮；用户也可结束本轮。已完成卡片不可通过重复请求增加完成次数。卡片保留题干与答案版本快照，但题目被撤回公开、停用或删除后必须重新检查访问权限，不向失去权限的人继续返回内容。

### 重点回顾

收藏由用户与题目 ID 唯一确定，重复收藏不创建重复记录。可在卡片或回顾列表取消收藏。收藏不改变题目可见性；题目被停用或失去访问权限时，不再参与收藏抽题，列表显示可用数量。

### 新增与导入

用户选择现有训练集合，填写题干；专业课与翻译可填写参考答案，英文问答仅填写题干。新增内容默认「仅自己可见」，保存后即可用于自己的训练与收藏。英文集合的题干需为英文，表单明确说明，不静默调用模型翻译用户稿件。

V1 提供单题表单和 JSON 文件批量导入，提供可下载模板。导入先预览题数与逐行错误，用户确认后整批提交；校验失败不产生半批数据。文件大小、条目数量和正文长度受配置限制。不把任意用户上传 PDF 自动解析纳入 V1。

默认提供上述五个集合，由后台维护，用户选择集合投稿。V1 不增加用户自建集合、分享链接或协作编辑功能。

## 每日签到与奖励

### 已确认的签到条件

采用「当日完成 5 道不同题后，可点击签到」，阈值可在后台配置；不要求答对、不消耗面试次数。当日题数跨训练类型累加，同一道题在同一天完成多次只计 1 道。题库不足时可完成较短的一轮，但不会把 1 道题重复计算成 5 道。

### 连续规则

服务端按 `Asia/Shanghai` 的自然日认定日期，不信任客户端日期。每天仅有一条签到记录。当日再次点击返回原记录；昨天已签到则连续天数加 1，否则从 1 开始。训练不会自动补签，跨过午夜后需要按新一天条件签到。

| 连续天数 | 当天新增面试次数 | 本轮连续累计获得 |
| --- | ---: | ---: |
| 7 | 1 | 1 |
| 14 | 2 | 3 |
| 21 | 3 | 6 |
| 28 | 4 | 10 |

即连续第 N 天且 N 为 7 的倍数时，新增 N/7 次。断签不扣回已获得次数；重新连续满 7 天可再次获得 1 次。V1 无补签、无奖励封顶，不擅自把规则改成每周固定奖励 1 次。

签到、连续天数计算、奖励发放和次数账本写入，在同一个 SQLite 写事务内完成。`(user_id, local_date)` 唯一，奖励关联唯一签到记录并受唯一约束；重复提交、并发、超时后重试都返回同一结果。任何一步失败整次回滚，不出现「打卡成功但奖励未到账」。

普通用户奖励写入现有 `credit_ledger`，类型为 `checkin_reward`，金额为 0，引用签到记录；不计入卡密消费金额。管理员可以打卡和累计连续天数，但不增加内部特殊额度，页面明确管理员不需要领取次数奖励。

配置调整只影响后续日期；当天已经开始训练的目标按该日保存的目标快照计算，避免管理员调整后使已达标用户突然失去资格。奖励周期 7 和递增公式属于已约定规则，V1 不提供随意更改公式的后台控件。

## 投稿审核与公开状态

题目保存 `owner_user_id`、`visibility=private/public`、`review_status=draft/pending/approved/rejected`，同时保存审核人、审核时间、驳回原因和更新时间。可见性与审核状态分别记录，不能仅以「待审核」推断公开权限。

流程为：新增私人草稿 → 用户主动提交 → 待审核且仍仅本人可练 → 管理员通过 → 全站公开；驳回则仍为私人题，用户看到原因并可修改后重提。取消提交恢复私人草稿。

后台审核员只能查看明确提交的稿件和已公开题，不默认浏览所有用户的私人草稿。普通管理员审核界面隐藏超级管理员和其他管理员的投稿身份信息，沿用现有账号可见范围。涉及该范围之外的投稿由超级管理员处理。官方题库由管理员维护，变更保留操作记录。

用户编辑已公开题时，确认提示「修改后将暂时转为私人，重新审核通过后公开」。保存后立即撤下旧公开版本，变为私人草稿，原用户收藏保留关联但不再向其他用户抽取。待审内容编辑时撤回当前审核，须重新提交；审核请求需携带版本号，管理员打开后题目已被修改则拒绝过期审批并提示刷新。

后台提供训练题库与投稿审核两个分区，按集合、状态、关键词筛选；审核页并列展示题干、参考答案、来源和必要图片，支持通过与填写原因驳回。删除、停用、公开、编辑均使用现有统一样式的站内对话框。

## 数据与文件

建议新增表：

| 表 | 主要内容与约束 |
| --- | --- |
| `training_collections` | 稳定集合 ID、类型、科目、显示名、启用状态 |
| `training_questions` | 集合、所有者、题干、答案、来源、公开/审核状态、版本；官方来源键唯一 |
| `training_question_assets` | 题目对应的本地参考图、排序、来源页码；按题目权限访问 |
| `training_favorites` | 用户与题目组合唯一 |
| `training_sessions` | 用户、筛选、创建时间、完成/结束状态 |
| `training_session_cards` | 轮次、位置、题目、内容快照、自评、完成时间；每轮题目唯一 |
| `training_daily_activity` | 用户、当地日期、目标快照；当日唯一 |
| `training_daily_questions` | 用户、日期、题目；当日完成去重 |
| `training_checkins` | 用户、日期、连续天数、连续起点；每天唯一 |
| `training_reward_grants` | 签到、奖励次数、账本引用；每次签到最多一笔奖励 |
| `training_review_events` | 提交、撤回、审核、停用等操作与版本记录 |

现有 `users` 和 `credit_ledger` 继续作为账号及次数依据，不创建第二套余额。通过下一版本 SQLite 单调迁移创建新表；官方素材按稳定来源键幂等导入，重复启动不重复插入，不覆盖管理员已经修改的答案。

私人题及其图片接口服务端检查所有权，不能只在前端隐藏。静态官方图表可随应用保存；用户内容不生成可绕过权限的公开地址。题目纯文本安全写入 DOM，参考答案如使用 Markdown 必须通过受限渲染，不执行 HTML。

注销或管理员删除账号时，删除该账号的收藏、训练历史、签到及私人投稿；已经审核公开的贡献保留并去除账号关联，不显示邮箱与旧用户名。保留的奖励记录去除账号身份，已注销账号不能恢复领取；新账号依现有注册规则重新处理，不在本次引入跨账号身份追踪。

## 接口与配置

新增 `/api/training/` 下的集合、首页、轮次、卡片完成、收藏、我的题目、批量导入、投稿、签到接口；后台使用 `/api/admin/training/`。所有写操作服务端认证，不能由请求体指定他人用户 ID。公开题、本人题与管理员审核分别使用明确查询条件。

配置文件新增 `[training]`：`timezone`、`round_size`、`daily_goal`、`checkin_requires_training`、`max_import_items`、`max_import_bytes`、`max_question_chars`、`max_answer_chars`。后台可管理每天目标与集合启停，部署和导入上限在配置文件统一管理。配置与后台设置的生效顺序写入说明，运行时数据库设置覆盖可管理项，配置提供初始值。

采用现有统一错误样式：无可用题给出返回筛选入口，失去访问权限停止展示并提供下一可用题，网络错误保留当前卡片且允许重试。未完成轮次可以恢复，重复请求不增加进度。领取成功以服务端回传余额刷新个人主页，页面不自行相加推算余额。

## UI 与可用性要求

桌面采用居中的阅读卡片和紧凑进度，移动端单列布局；收藏和下一题操作在拇指可达区域，避免固定栏遮住参考答案。支持键盘焦点、清晰按钮状态、屏幕阅读器标签与减少动态效果设置。

打开参考答案不跳走当前阅读位置；大图独立放大，长公式与表格在自身容器内滚动。签到成功使用就地完成反馈，奖励仅在实际发放时展示；不连续弹出庆祝弹窗，不用浏览器 `alert`、`prompt` 或 `confirm`。

此模块不改变正式面试的全程录音、倒计时、结束、点评触发、PPT 放映与回放行为。切到训练页不启动面试或扣减次数。

## 验收与验证

1. 96 道专业课题均对应参考答案及来源，跨页、图表与答案编号不误切；31 段翻译逐对核验，53 道口语题没有虚构答案。导入报告能定位缺失或重复项。
2. 全量/收藏/科目筛选正确，一轮不重复；空收藏、少量题库、全部停用、刷新恢复与重复完成请求都有明确结果。
3. 两个普通用户互不可见私人题与图片，收藏不能越权；普通管理员看不到未提交私人草稿，超级管理员账号层级不被投稿列表绕过。
4. 待审仍私人，通过才公开；公开题编辑需重新审核，旧版本审批不能发布新内容，驳回原因用户可查看。
5. 中国时区午夜、同日重复、并发签到、断签重置、7/14/21 天递增、奖励事务回滚均通过测试；免费奖励不计入消费金额。
6. 删除账号后无孤立私人数据，公开贡献不再携带个人身份；重复导入与重复启动不增加题数或奖励。
7. 浏览器检查桌面与窄屏的完整训练、收藏、投稿、审核、签到与奖励展示；回归账号登录、面试扣次和后台管理关键流程。测试使用隔离数据库，不向正式账号灌入模拟奖励。

用户已确认训练后签到并补充顺序复习模式；按本设计推进题目整理、数据库迁移、前后台实现和验证。
