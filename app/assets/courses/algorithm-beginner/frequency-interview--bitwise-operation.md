# 常用的位操作

## 学习目标

掌握按位与、或、异或及安全位移，理解清除最低有效位的用途。

## 常见操作与语义

与 `&` 只保留两边都为 1 的位，或 `|` 保留任意一边为 1 的位，异或 `^` 保留不同的位。相同数异或为 0，任何数与 0 异或仍为自身，因此成对出现的数可以被异或抵消；但前提是题目保证这种出现次数结构。

```cpp
int bitCount(unsigned int x) {
    int total = 0;
    while (x != 0) {
        x &= x - 1;
        ++total;
    }
    return total;
}
bool powerOfTwo(unsigned int x) {
    return x != 0 && (x & (x - 1)) == 0;
}
```

`x & (x-1)` 清除最低的一个 1。判断 2 的幂要先排除 0，否则 0 也会通过位表达式。计数循环次数等于 1 的个数。

## 数值类型决定边界

C++ 中对有符号负数位移、移动位数超过类型宽度、把 1 左移到有符号不可表示范围，都容易产生问题。构造掩码时选择合适的无符号类型，并保证位数合法；打印二进制时区分值本身与其固定宽度表示。

对非负整数且模数为 2 的幂时，可以用掩码代替取模；模数不是 2 的幂就不能这样做。位技巧的收益建立在清楚输入范围和语言规则的基础上，不应牺牲可读性去替换所有普通算术。

## 动手练习

2. 用 0、1、2、3、8 验证 2 的幂判断。
3. 对 [4,1,4,2,2] 用异或找单次出现元素，并解释前提变化后为何可能失效。
