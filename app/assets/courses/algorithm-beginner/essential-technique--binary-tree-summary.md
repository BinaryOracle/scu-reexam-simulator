# 二叉树系列算法核心纲领

## 学习目标

理解前中后序的执行时机，选择遍历或分解子问题的组织方式。

## 三个位置与一次递归

进入节点时是前序位置，完成左子树后是中序位置，完成两棵子树后是后序位置。它们代表当前已经知道哪些信息，而不仅是打印节点的三种顺序。父节点传递的深度可在前序使用，子树计算结果要到后序才完整。

```cpp
int height(Node* root) {
    if (!root) return 0;
    int left = height(root->left);
    int right = height(root->right);
    return 1 + max(left, right);
}
```

这里采用分解方式，每次调用只承诺返回当前子树的高度。如果采用遍历方式，则带上深度参数，在访问节点时更新最大值；这时需要明确外部状态何时初始化。

## 从树扩展到其他问题

回溯的节点是已作出的选择，子节点是下一步选项；动态规划的递归树中存在重复状态；BFS 按层探索状态图。相似的递归形式不代表处理规则相同：树通常无需去重，图需要防止环；回溯常在返回时撤销路径，普通 DFS 的全局访问标记则不一定撤销。

分析递归复杂度时计算访问次数和栈深度。平衡二叉树高度是 O(log n)，退化树高度可能是 O(n)，深树上递归实现也可能受到调用栈限制。

## 动手练习

1. 画一棵三层树，标出每个节点的前序、中序和后序位置。
2. 用遍历与分解两种方式分别求最大深度。
3. 说明“子树节点数”和“当前根到节点路径”分别适合在哪个位置处理。
