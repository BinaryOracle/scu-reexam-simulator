# 邮箱验证码登录

前台使用邮箱和 6 位邮件验证码登录，账号密码入口继续保留；后台使用管理员用户名与密码。首次邮箱登录创建独立普通账号，默认用户名为完整的规范化邮箱，初始密码随机生成，按后台当前设置发放初始体验次数；模拟面试与上机考试权限默认开启，每日训练与算法题带刷权限默认关闭。后续登录不会重置管理员调整过的权限，不按相似用户名匹配已有账号。若邮箱文本已被其他账号用作用户名，返回冲突，由管理员处理，避免关联到他人身份。后台创建用户时可关联唯一邮箱，使邮箱登录访问该账号和记录。账号停用阻止所有登录方式。

## QQ 邮箱配置

在 QQ 邮箱设置中启用 SMTP，并取得授权码。在本地 `config.toml` 中添加以下配置；不要将真实授权码写入示例文件或版本库。

```toml
[email_auth]
enabled = true
smtp_host = "smtp.qq.com"
smtp_port = 465
smtp_security = "ssl"
smtp_username = "你的完整QQ邮箱@qq.com"
smtp_password = ""
smtp_password_env = "SCU_SMTP_PASSWORD"
from_email = "你的完整QQ邮箱@qq.com"
from_name = "知序复试模拟系统"
```

将授权码放入服务进程的 `SCU_SMTP_PASSWORD` 环境变量，也可在被 Git 忽略的本地配置中填写 `smtp_password`。该字段非空时优先于环境变量。腾讯企业邮箱将服务器改为 `smtp.exmail.qq.com`，填写企业邮箱完整地址和对应 SMTP 凭证；端口和授权方式以邮箱服务商要求为准。也支持 `smtp_security="starttls"` 和相应端口，始终校验 TLS 证书。

## 使用与限制

点击获取验证码后，页面显示发送邮箱和重发倒计时；验证码默认 300 秒有效，60 秒后可重发。单码最多输错 5 次，重发使旧码失效，成功登录后不可重复使用。发送尚未完成或发送失败时验证码不可登录，失败不会伪报邮件已发送；发送失败后仍保留冷却和频率计数。

触发频率限制时，登录页及个人主页的验证码入口会显示具体等待秒数，并禁用发送按钮、显示重发倒计时。等待时间以服务端 `Retry-After` 为准，缺失或无效时默认 60 秒；刷新页面后再次请求仍会恢复剩余等待时间。小时发送限额触发时，显示实际限流窗口的剩余秒数。

默认每小时每邮箱最多发送 5 次，每来源 IP 最多发送 30 次、校验 60 次；限制均可在 `[email_auth]` 配置，示例文件列出全部参数。验证码使用带随机盐的 scrypt 哈希保存，不返回给前端、不打印到应用日志。SMTP 网络发送期间不持有数据库写事务；发送和消费使用数据库事务处理并发请求。初始次数写入账本，后续登录不再发放。

接口为 `POST /api/auth/email/code`（email）、`POST /api/auth/email/login`（email/code）和只返回启用状态的 `GET /api/auth/email/settings`。登录响应与密码登录一致，包含 token 和安全账号信息，禁止缓存。发送接口失败返回可操作的中文说明，429 同时返回 Retry-After；未配置或未启用 SMTP 时返回 503。

个人主页可修改用户名与登录密码。用户名保留非空及唯一性要求，不限制格式或复杂度；改名不会修改绑定邮箱。邮箱仅通过“变更绑定邮箱”更换，验证码发送到新邮箱且必须验证成功，其他设备会话随之失效。绑定邮箱的账号通过发送到当前邮箱的专用验证码修改密码或注销；尚未绑定邮箱的旧账号使用当前密码验证。不同用途的验证码不能相互使用。密码更新后需重新登录，普通账号注销会清理私有资料；超级管理员不能自行注销。

登录密码默认遮掩，点击后通过 `POST /api/profile/reveal-password` 单独读取本人密码，再次点击隐藏。离开个人主页、切换浏览器标签、退出登录或会话失效会清除页面中的原文，迟到的读取响应不能重新显示密码。接口验证当前有效会话并禁止缓存，普通账号信息接口不返回密码；旧账号没有可解密副本时须修改密码或成功进行一次密码登录后才能查看。

SQLite v13 增加唯一邮箱、验证码及发送/校验限流表，v14 增加绑定邮箱及敏感操作的专用验证码存储。升级保留旧账号、密码、余额和记录；原模块权限字段仅为历史兼容保留，不再参与访问判断，后台和 API 已移除开关。上线前备份数据库及密码查看密钥。
