# 二叉树心法（构造篇）

## 学习目标

根据遍历序列划分子树范围，理解唯一构造所需条件。

## 前序找根，中序切分

假设节点值互不相同，前序遍历第一个值是根；在中序中找到根的位置，左边属于左子树，右边属于右子树。递归时传递索引范围，不必反复复制子数组。先建立中序位置表，可避免每层线性搜索。

```text
build(preStart, inLeft, inRight):
    如果 inLeft > inRight，返回空树
    value = preorder[preStart]
    split = position[value]
    leftSize = split - inLeft
    root.left  = build(preStart + 1, inLeft, split - 1)
    root.right = build(preStart + 1 + leftSize, split + 1, inRight)
    返回 root
```

示例前序 [2,1,3]、中序 [1,2,3]，根为 2，左右子树大小都为 1。后序的最后一个值是根，也可配合中序划分，但前后序组合通常不能唯一确定只有单个孩子的方向。

## 别跳过输入条件

如果有重复值，单个值到索引的映射不足以唯一定位分割点；如果遍历不合法或长度不同，应按题目条件拒绝，而不是越界继续构造。最大二叉树则按区间最大元素作为根，这是一种不同的分割规则。

使用位置表构建合法树通常 O(n) 时间、O(n) 映射空间，递归栈取决于树高。最大值逐段线性扫描的构造在退化输入上可能 O(n²)，不要把所有“构造二叉树”都写成同一个复杂度。

## 动手练习

1. 用前序 [3,1,2,4]、中序 [1,2,3,4] 画出树并验证遍历。
2. 写出中序配合后序时的根位置和左右子树范围。
3. 举例证明仅有前序和后序时，单孩子树可能不唯一。
