# 二叉搜索树心法（基操篇）

## 学习目标

维护整个子树的有序约束，掌握搜索、插入及三类删除情形。

## 合法性不是只比较父子

严格二叉搜索树要求左子树所有值小于根，右子树所有值大于根。判断合法性时应把祖先给出的上下界沿递归传递，不能仅比较当前根与直接孩子。

```cpp
bool valid(Node* root, long long lower, long long upper) {
    if (!root) return true;
    if (root->val <= lower || root->val >= upper) return false;
    return valid(root->left, lower, root->val)
        && valid(root->right, root->val, upper);
}
```

若节点值是 int，可使用 long long 的最小值和最大值初始化边界。示例不接受重复值；允许重复的树必须另行规定重复值放在哪边，并统一所有操作的比较规则。

## 操作都要返回新的子树根

查找时根据大小向一个方向前进。插入到空位置后，让父节点重新连接返回值。删除分三类：叶子直接去掉；只有一个孩子时用该孩子替代；两个孩子时取右子树最小值或左子树最大值替换，再在对应子树中删除该节点。修改根节点时尤其不能忽略返回值。

搜索、插入和删除通常为 O(h)，h 为树高。普通 BST 不保证平衡，按有序输入逐个插入可能退化成链表，使单次操作变为 O(n)。不要把“二叉搜索树”与“自平衡搜索树”的复杂度承诺混用。

## 动手练习

1. 构造一棵局部父子比较通过、但违反祖先约束的树。
2. 依次删除叶子、单孩子节点和双孩子节点，检查中序仍有序。
3. 用递增顺序插入五个值，计算树高并比较平衡排列。
