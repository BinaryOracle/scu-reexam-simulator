# 小而美的算法技巧：前缀和数组

## 学习目标

用额外一个起始位置统一区间求和，并把包含排除推广到二维。

## 用左闭右开区间减少边界分支

定义 `prefix[i]` 为原数组前 i 个元素的和，令 prefix[0]=0。区间 `[left, right)` 的和就是 `prefix[right]-prefix[left]`，区间从 0 开始时也不需要特殊处理。

```cpp
vector<long long> prefix(a.size() + 1, 0);
for (int i = 0; i < (int)a.size(); ++i)
    prefix[i + 1] = prefix[i] + a[i];
// 0 <= left <= right <= a.size()
long long rangeSum = prefix[right] - prefix[left];
```

例如 a=[3,-1,4]，prefix=[0,3,2,6]，索引区间 [1,3) 的和为 6-3=3。负数不会影响前缀和的正确性，但求和结果可能溢出，需要按题目范围选择数值类型。

## 二维包含排除

二维数组中，令 P[i+1][j+1] 表示左上角到 a[i][j] 的矩形和，转移为当前值加上方、加左方、减重复的左上方。查询矩形 `[r1,r2)×[c1,c2)` 时使用：

$P[r2][c2]-P[r1][c2]-P[r2][c1]+P[r1][c1]$。

一维预处理 O(n)，每次求和 O(1)；二维预处理 O(mn)，每次矩形求和 O(1)。这适合静态数组的多次查询。若原数组经常修改，更新所有后续前缀可能很贵，应另选支持动态更新的结构，不能只看查询成本。

## 动手练习

3. 解释为什么前缀数组长度比输入长度多 1，并测试空区间。
