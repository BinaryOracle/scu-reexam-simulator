# 小而美的算法技巧：差分数组

## 学习目标

把区间加法转为差分端点更新，正确处理区间末尾与最终还原。

## 记录相邻元素的变化

令差分 d[0]=a[0]，其余 d[i]=a[i]-a[i-1]。对差分做一次前缀累加即可恢复原数组。若希望闭区间 [l,r] 每个位置都加 v，只需让 d[l] 加 v，并在 r+1 位置减 v，表示从下一个位置起停止这次影响。

```cpp
vector<long long> diff(n + 1, 0);
// 每次更新都满足 0 <= l <= r < n
for (const auto& update : updates) {
    int l = update[0], r = update[1];
    long long value = update[2];
    diff[l] += value;
    diff[r + 1] -= value;
}
vector<long long> answer(n);
long long running = 0;
for (int i = 0; i < n; ++i) {
    running += diff[i];
    answer[i] = running;
}
```

示例以全零数组为起点，额外的第 n 个位置作为哨兵。如果原数组非零，需要先根据原值建立差分，再处理更新。不同更新可以直接相加，即使区间重叠也成立。

适用场景是批量区间增减后统一读取结果，总成本为 O(n+q)，而不是每次遍历整个区间。差分不直接适用于区间赋值、乘法或每次更新后立即查询任意区间的全部要求；选择之前要检查题目操作是否具有可叠加性。

## 动手练习

1. 对长度 5 的全零数组依次执行 [1,3]+2、[2,4]-1，手算差分与结果。
2. 修改示例以支持非零初始数组。
3. 测试整个区间、单点和末尾区间，检查 r+1 哨兵是否正确。
