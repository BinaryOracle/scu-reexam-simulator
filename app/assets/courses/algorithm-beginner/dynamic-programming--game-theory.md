# 经典动态规划：博弈问题

## 学习目标

用双方最优行动定义区间博弈状态，避免把对手当成固定策略。

## 状态必须包含双方的最优反应

考虑一排数，每次只能从两端取一个，两人轮流行动且都希望自己的总分最大。用 `diff[l][r]` 表示轮到当前玩家时，该玩家最终得分减去对手得分的最大差值。取左端后，剩下状态中“当前玩家”换成对手，所以要减去其最优差值。

$diff[l][r]=\max(a[l]-diff[l+1][r],\ a[r]-diff[l][r-1])$。

```cpp
long long scoreDifference(const vector<int>& a) {
    int n = (int)a.size();
    if (n == 0) return 0;
    vector<vector<long long>> dp(n, vector<long long>(n));
    for (int i = 0; i < n; ++i) dp[i][i] = a[i];
    for (int len = 2; len <= n; ++len)
        for (int l = 0; l + len <= n; ++l) {
            int r = l + len - 1;
            dp[l][r] = max(a[l] - dp[l + 1][r], a[r] - dp[l][r - 1]);
        }
    return dp[0][n - 1];
}
```

按区间长度从小到大计算，保证短区间已经求解。结果为正表示先手得分更高，0 表示平分。这个状态也可改写成一对“先手得分、后手得分”，但转移时必须交换角色。

不要使用“每次拿当前更大的端点”作为通用最优策略，局部收益可能给对手留下更好的选择。时间和空间均为 O(n²)，若只需要结论且题目有特殊限制，才进一步寻找数学简化。

## 动手练习

1. 对 [1,5,2] 手算最优差值。
2. 找一个贪心取较大端点失败的数组。
3. 把差值状态改写成双方得分状态，并验证两种写法一致。
