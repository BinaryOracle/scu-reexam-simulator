# 一个方法团灭 LeetCode 股票买卖问题

## 学习目标

以天数、剩余交易规则和持有状态组织股票动态规划，区分冷冻期与手续费。

## 状态描述的是当天结束之后

不持股与持股是两个不同状态。每一天可以保持原状态，也可以通过买入或卖出从另一个状态转移。初始不持股收益为 0，初始持股收益可设为负无穷，表示尚未完成任何合法买入。

以下示例允许任意多次交易，但同一时刻最多持有一股，没有手续费或冷冻期：

```cpp
long long profit(const vector<int>& prices) {
    long long cash = 0, hold = -(1LL << 60);
    for (int p : prices) {
        long long oldCash = cash, oldHold = hold;
        cash = max(oldCash, oldHold + p);
        hold = max(oldHold, oldCash - p);
    }
    return cash;
}
```

使用旧状态明确两次转移都来自前一天。允许交易次数越多不代表可以同时持有多股；最终答案通常来自不持股状态，不能把尚未卖出的股票直接按 0 成本计入收益。

## 规则变化体现为依赖变化

只允许一次交易，买入时不能使用以前卖出获得的收益重新投资；最多 k 次交易应增加交易次数维度，并明确在买入还是卖出时计数。手续费可在一次完整交易的一个环节扣除，不能买卖两边都扣。冷冻期则限制卖出后多久能重新买入，需要依赖更早的现金状态或额外状态。

基本两状态版本时间 O(n)、空间 O(1)；加入交易次数后通常 O(nk)。先写规则，再写转移，不要把所有股票题当成同一个循环直接提交。

## 动手练习

1. 对 [1,3,2,5] 比较只允许一次与允许多次交易的收益。
2. 在卖出环节扣除手续费，并手算结果。
3. 写出卖出后冷冻一天的状态依赖，说明为何不能只修改手续费数值。
