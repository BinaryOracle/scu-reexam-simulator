JUDGE BRIDGE

连接评测提交插件

  1. 先下载插件 ZIP 并解压到一个固定目录，之后不要移动或删除该目录。
  2. 在 Chrome 或 Edge 打开扩展程序管理页，开启开发者模式，选择“加载已解压的扩展程序”，选中解压出的 browser-extension 文件夹。
  3. 无需填写知序网站来源；插件包已由管理员统一配置本站地址，并会自动连接知序页面。
  4. 刷新知序页面，在同一浏览器登录当前题目对应的平台：洛谷或力扣中国区（leetcode.cn）。LeetCode 题目搜索、导入和提交都使用中国区站点；保持该站点标签页打开。
  5. 在题目工作区检测平台登录状态；连接成功后即可提交。

插件在当前浏览器内提交代码，知序服务器不会收到平台密码或登录 Cookie。若平台要求安全验证，请按页面提示完成。
